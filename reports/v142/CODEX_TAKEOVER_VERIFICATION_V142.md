## 남은 사항 / 다음 단계

1. **공간자료 부족은 미해결이다.** 43개 선정 대상 중 B-017은 미연결이며, B-023/B-025/B-028의 유역 경계도 확보되지 않았다. 대표점을 유역 경계나 정확한 활동 범위로 바꾸지 않았다.
2. **이번 턴에서 Linux E2E, 전체 `finalize:v140`, Preview·Production 검증을 실행하지 않았다.** 이전 79/79 결과를 이번 소스의 전체 release gate 결과로 재사용하지 않는다. 이번 결과만으로 main 병합을 권고하지 않는다.
3. 주변 화면 관찰 중 B-001 카드가 본문에는 ‘월별 평년값(1991–2020)’을 표시하지만 하단 ‘자료기간’에는 ‘1991년’을 표시하는 기존 불일치가 보였다. 이번 V142 영향 범위 밖으로 기록하며, 다음 공개 문구/기간 표시 점검에서 수정·재검증이 필요하다.
4. 승인 후 변경 내용을 검토해 커밋·push하고, **한 개의 고정된 빌드**에 대해 CI 전체 gate 및 Linux E2E를 실행한다. 동일 디렉터리에서 동시에 build를 다시 만들지 않는다.
5. 해당 커밋의 로그인된 Preview에서 이번 영향 화면·카드 연결·지도 출처 전환을 다시 확인한다. 실패 원인과 성공 근거를 기록한 뒤 병합 여부를 별도로 결정한다.
6. 이후 한국어 문구를 Claude로 최종 감수하더라도 측정항목·기간·단위·집계 대상은 바꾸지 않고 문장만 다듬는다. 새 탭이나 새로운 데이터 수집 없이 기존 화면을 마무리한다.
