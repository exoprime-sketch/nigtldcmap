# V144 데이터별 분석 재검토와 수정 결과

## 판정

- 152개 데이터 각각에 참고 플랫폼, 사용자 질문, 필요한 분석, 단위·범위 해석 기준을 작성했다.
- 152개 상세 경로의 로딩·화면 구조를 브라우저에서 확인했다. 선택 가능한 118개 화면에서 첫 선택기를 한 번씩 변경해 내용 변화를 확인했다.
- 이것은 **152개 분석의 최종 수용 완료가 아니다.** 모든 선택 조합과 원천 산술을 검증한 것처럼 표시하지 않았다. 최종 수용 항목은 `pending-evidence`로 남겼다.
- 이전의 ‘152개가 열린다’ 검증과 달리, 실제 화면에서 빈 국가통계 차트·출처 불일치·분류체계 오적용 등 의미 오류를 찾아 수정했다.
- 원자료 측정값·다운로드 파일·공간 경계는 변경하지 않았다. 새 탭을 추가하지 않았다. 기존 V142/V143 작업을 보존했다.

## 152개별 결과

- [데이터별 검토표](ELEMENT_BENCHMARK_REVIEW_V144.md): 코드·데이터명·벤치마크·질문·필요 분석·해석 기준·남은 쟁점의 1:1 대응.
- [구조화된 검토 및 브라우저 근거](element-benchmark-review-v144.json): 기존 V143 근거와 이번 근거를 분리하고 각 빌드 범위를 기록.
- [브라우저 근거 독립 검산](review-evidence-audit-v144.json): 경로/선택/반응형 기본 확인 및 A-006·E-008 원자료 대조 7/7 PASS. 전체 의미 검증 게이트와는 별도.

18개 공식 참고 자료를 사용했다. 예: WDI 국가 시계열, ILOSTAT 노동지표 구분, OWID 에너지원 구성, CCKP 시나리오·기간, GFW 지역별 변화, WIPO 유형별 집계, OECD ODA 비교, 공공데이터포털의 검색·자료정보 명칭. 동일한 플랫폼을 여러 데이터에 참고할 수 있지만 각 데이터의 질문·단위·비교 대상을 별도로 정했다. 벤치마크에서 새 측정값을 가져오지는 않았다.
