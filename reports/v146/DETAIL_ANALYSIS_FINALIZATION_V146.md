# V146 상세 분석 화면 개선·검증 결과

## 결과와 범위

- 데이터 찾기에서 진입하는 **152개 상세 화면의 대표값/KPI 카드 제거**. CSS로 가린 것이 아니라 실제 화면 구성에서 제거했습니다.
- 홈·데이터 찾기의 요약 카드는 유지했습니다. 새 탭은 만들지 않았습니다.
- 상세 화면은 `제목과 간단한 설명 → 분석 조건 → 차트·분석표 → 접어서 보는 자료정보` 순으로 정리했습니다.
- 원자료의 수치·단위·기간·출처는 유지합니다. 숫자 카드를 없애는 것을 데이터 자체를 삭제하는 것으로 처리하지 않았습니다.
- 기존 작업 트리의 V142~V145 변경을 보존했습니다. 이번 결과는 로컬 구현·검증이며 commit·push·병합·Vercel 배포는 하지 않았습니다.

### 검증 범위를 혼동하지 않기 위한 설명

- 실제 카드 클릭과 선택 조작은 V146 개선 중 반복 빌드에서 수행했습니다. 마지막 빌드에서는 이미 확인한 152개 상세 URL을 다시 열어 레이아웃을 재검사했습니다. 개별 카드 클릭 당시 빌드는 JSON의 `cardClickBuild`에 구분했습니다.
- 반응형 검사는 최종본과 같은 반응형 CSS가 적용된 반복 빌드에서 수행했습니다. 152개 전부를 모든 화면 폭에서 검사한 것은 아닙니다.
- B-003~B-007은 최초 검사에서 도구의 3초 대기 한도를 넘긴 경우가 있었습니다. 뒤이은 관찰에서는 모두 로딩 완료를 확인했습니다. 대용량 기후 자료의 로딩 속도는 별도 성능 개선 대상으로 남깁니다.
- 152개 화면의 열림·카드 제거를 확인한 것과, 152개 원자료의 모든 수치 및 모든 필터 조합을 재검산한 것은 다릅니다. 후자를 완료했다고 판정하지 않습니다.
- 전체 release gate, Linux 시각 비교, Preview·Production 검증은 이번 작업에서 실행하지 않았습니다. 기존 gate의 과거 PASS를 이번 수정본의 결과로 사용하지 않습니다.
- B-017 평가구역 경계와 B-023/B-025/B-028 유역 경계 미확보 문제를 이번 상세 화면 개선으로 해결했다고 보지 않습니다.
