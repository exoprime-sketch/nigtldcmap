## 벤치마킹을 적용한 방식

- [공공데이터포털](https://www.data.go.kr/index.do): 데이터명·제공기관·기간·다운로드를 분리하고 개발용 설명을 주 내용과 구분하는 정보 구조.
- [World Bank CCKP](https://climateknowledgeportal.worldbank.org/download-data): 기후 변수·기간·시나리오·지역 구분. 원자료의 평년 기간을 임의 변경하지 않음.
- [FAOSTAT Land Cover 방법](https://files-faostat.fao.org/production/LC/LC_e.pdf): 위성제품·분류·공간해상도가 다른 토지피복 계열을 따로 비교.
- [Global Data Lab GVI](https://globaldatalab.org/gvi/about/): 0~100 취약성 점수의 방향과 권역 단위 유지.
- [SDG Index 방법](https://dashboards.sdgindex.org/chapters/part-5-methods/): 정규화 점수와 원래 지표 단위 구분. 세부지표를 목표 평균으로 임의 계산하지 않음.
- [기존 조사형 LPI 메타데이터](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/LP.LPI.OVRL.XQ): 1~5점 지표의 분야 비교. 새로운 LPI 2.0과 시계열을 섞지 않음.
- [HydroSHEDS 기술 문서](https://data.hydrosheds.org/file/technical-documentation/HydroSHEDS_TechDoc_v1_4.pdf): 8방향 유향과 유량을 구분.
- [UNESCO UIS 용어집](https://databrowser.uis.unesco.org/glossary): 성별 졸업자 비율의 분모 및 연구자 절대수/인구 대비 지표 구분.

152개 검토표의 링크는 해당 데이터의 분석·해석 기준이다. 152개 별도 외부 페이지를 이번에 모두 방문했다는 의미가 아니다. C-002는 저장소 다운로드 자료와 대조했으며, UNFCCC 원 PDF는 접근 시간 초과로 이번에 재확인하지 못했다.

## 남은 경계와 배포 조건

1. B-017 평가구역 경계, B-023/025/028 유역 경계는 아직 없다. 상세 분석 개선을 지도 경계 확보 완료로 표시하지 않는다.
2. B-039의 ‘개소 수’/‘MW’ 충돌 1개 계열은 원기관 또는 데이터 작성자 확인이 필요하다. 그 전에는 숫자 차트에서 제외한다.
3. 위 결측 항목과 자료 준비 상태 데이터는 시각화 코드만으로 완성할 수 없다. 데이터 제공 또는 산출 근거 확정이 필요하다.
4. 모든 필터 조합·모든 원기관 최신 수치의 전수 재승인, GitHub Linux E2E·전체 release gate·Preview·Production 검증은 이번 완료 범위가 아니다.
5. 기존 감사의 삭제된 A-016 KPI 타일 기대값을 실제 구성 차트·연도별 값 검사로 교체했다. B-001 계절표 및 C-002 인벤토리 표 등 새 분석에 맞춰 감사도 보완했다. 해당 감사의 브라우저 실행은 하지 않았고, 배포 전 Linux CI로 확인해야 한다.
6. 이번 변경을 기존 미커밋 작업과 함께 검토해 별도 후보로 묶은 후 CI → Preview 화면 확인 → 승인된 병합·production 검증 순으로 진행한다. 검토 중에는 동일 `build/`를 여러 세션에서 덮어쓰지 않는다.
