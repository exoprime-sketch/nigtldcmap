# 데이터 지도 클릭 정보 전수 검토 (V163-T3, 2026-10-03)

대상: 데이터 지도에서 대상을 클릭했을 때 ① 지도 위 팝업 ② 오른쪽 '지도 분석' 패널(선택 카드)
범위: 베트남 72 + 방글라데시 38 = 110 레이어. 레이어마다 자동으로 켜고 클릭해 팝업·패널 문구를 수집함(`scratchpad/audit2/map.mjs`). 그 문구를 레이어별로 읽고 판정함.
원칙: 용역사 지시 이후라 **화면 구조·항목 구성은 그대로** 두고, 문구·표기 결함만 고침.

## 벤치마킹 기준
- Esri ArcGIS 팝업 가이드: 제목, 원문 필드명 대신 별칭, 불필요 필드 숨김, 숫자 형식(천 단위·소수), 설명 문구 — https://www.esri.com/arcgis-blog/products/arcgis-online/mapping/configure-pop-ups-basics
- Map UI Patterns 'Info pop-up': 점진적 공개(팝업은 핵심만, 자세한 것은 패널), ObjectID 같은 무의미 코드 제외, 확대·상세 이동 동작 — https://mapuipatterns.com/info-popup/
- 위 기준을 이 플랫폼에 적용한 규칙
  1. 팝업 = 레이어명 / 대상 이름 · 지표와 값·단위 / 기준 연도
  2. 같은 대상은 팝업·패널·탐색 버튼에서 같은 이름("한글명 (현지명)")
  3. 같은 값은 팝업과 패널에서 같은 지표명과 같은 '값 없음' 표기
  4. 원문 코드·필드명·작성 메모는 화면에 없음. 분류값은 한국어 명칭(원천 정의 기준)
  5. 숫자는 천 단위 구분, 단위는 값의 단위(레이어의 개수 단위 '곳'과 섞지 않음)
