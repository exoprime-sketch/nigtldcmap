   인쇄된 열 이름으로 결속하도록 고쳤고 An Giang 352,425 / 38,545 / 31,815 ha 로 원천과 일치한다.

   적용범위가 `status`, 현행 여부가 `sourceUrl` 로 나가고 있었다. 열 이동을 감지해 이름으로
   재결속했다.

   않아 드러나지 않았고, Playwright 도입 첫 실행에서 잡혔다).
6. **A-002 의 유의사항과 홈 카드가 CPIA 시절(2005–2015)을 말하고 있었다.** 현재 자료는

## 7. 릴리스 게이트

`npm run finalize:v136` → **46 / 49 통과**. 실패는 `V132_PORTFOLIO` 와 그 파생 2건이며
**이번 세션 이전부터 있던 것**이다.

원인은 확인됐다. 이 감사는 요소별 개체 수를 **저장소의 구 `public/data`** 에서 읽고 화면은
새 데이터가 든 빌드에서 읽는다. 같은 감사를 후보 빌드로 돌리면 지적 대상이 11개 → 3개로
줄고, 남는 셋은 다음과 같다.

- **C-007** — 후보 데이터로는 모든 조건을 만족한다. 구 데이터에서 개체 0건으로 집계되어
  "개체가 없는데 목록이 있다"로 잡힌 것이다.
- **E-018 · E-020** — 연도 열이 없다. E-018 은 `1999 설립 / 2020 진출` 이 한 칸에 들어 있고
  E-020 은 `연 1회 공모` 뿐이다. 연도 추세를 그리려면 연도를 만들어내야 하므로 그리지 않았다.
  "모든 포트폴리오 화면은 연도 추세를 가져야 한다"는 감사 기대가 이 둘에는 성립하지 않는다.

감사 기대치 조정과 데이터 승격은 소유자 결정이므로 이번 세션에서 바꾸지 않았다.
