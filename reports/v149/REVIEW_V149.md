# V149 — 홈·목록 복귀·공용 집계·반응형

이번 범위는 사용자의 5개 요청이다. 기존 V142–V148 변경사항을 보존했으며, 전체 152개 분석 내용의 새로운 전수 재감사로 보고하지 않는다. 커밋·push·PR·배포는 하지 않았다.

## 반영 내용

1. Finder에서 상세보기/지도/다운로드로 이동하기 직전 화면 위치를 보관한다. 목록으로 돌아오면 국가·검색어·대분류·그룹·기관·기술뿐 아니라 정렬·자료연도·제공 형태·상세검색 펼침·추가 로딩 수를 복원한다. 상세 진입 후 바뀐 문서 높이를 unmount 시 저장하던 문제와 App의 강제 상단 이동을 제거했다.
2. 홈 주제별 데이터 영역 삭제. 기존 상단 탭은 유지.
3. 홈 주요 지역 데이터: 공용 지도 열람 순위 1위의 실제 위치/지역 자료를 가벼운 SVG로 표시. 전체 지도 진입 시 같은 자료와 선택조건 전달. 지도엔진을 홈에 추가로 구동하지 않는다.
4. 주요 데이터 조회순/최신순: 실제 집계가 있으면 제공 자료 전체 중 상위 8개. 없으면 기존 선정 8개와 집계 전 안내. 최신순은 자료 갱신일 기준이며 전망 대상연도가 아니다.
5. 홈 지도·정렬·버튼·좁은 화면 입력창을 보완. 필요한 지도 해석 주의는 축소 지도에도 남겼다.

## 실행한 검증

- TypeScript와 최종 production build 성공. 최종 main.e1acbcfb.js.
- React 단위 테스트 18개 파일 / 206개 PASS.
- 서버 API 계약 테스트 10개 PASS. 실제 원격 Redis에는 연결하지 않았다.
- 인앱 Chromium, 실제 화면 조작으로 확인:
  - 1280px 목록, 지도 제공/데이터명 정렬, 42개 로딩 후 D-008 진입 → 브라우저 Back: scrollY **5482 → 5482**, 42개 유지.
  - 390px 목록, VNM/E/지도 제공/데이터명, E-005 진입 → 화면 내 '검색 결과로 돌아가기': scrollY **2110 → 2110**, 5개 및 상세검색 펼침 유지.
  - 미연결 홈: 대표 송전망·집계 전 안내, 임의 조회수 없음.
  - 별도 fixture 홈: 지도 A-023, 카드 B-005 → A-023 → A-003. 실제 이용 통계가 아님.
  - 홈 인기 지도 버튼 → 데이터 지도 primary=A-023, 2021 WRI 자료/236곳/41,350MW 확인.
  - 최신순 버튼 → 갱신일 표시 및 순서 변경. 주제별 데이터 요소 0.
  - 홈·Finder·E-005 상세·지도·다운로드 각각 320/390/768/1024/1440/1920px, 총 **30개 화면-크기 조합에서 문서 가로 넘침 0**.
  - 모바일 홈/목록/지도 스크린샷으로 읽기·버튼 배치 확인. 브라우저 JavaScript error/warn 0.

미연결 API의 503은 의도된 상태이며 핵심 자료 요청 실패와 구분한다. 테스트용 API 응답은 UI 경로 확인에만 사용했다. 실기기 iOS/Safari 및 152개 화면 전체의 6개 크기 검사는 이번에 수행하지 않았다.

기존 V139/V140 홈 감사는 삭제한 주제 바로가기가 아닌 최신순, SVG/카드 요약, 동적 8개 자료를 검증하도록 기대값을 조정했다. 그 전체 브라우저 감사와 Linux 시각 baseline은 이번에 재실행하지 않았다.
