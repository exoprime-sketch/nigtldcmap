# 상세 화면 '활용 사례' 명칭 변경 및 'AI 생성' 표시 통보(V169)

- 수신: 플랫폼 화면 개발 용역사
- 대상: '데이터 찾기' 상세 화면 → '데이터 설명' 영역의 '활용 사례'
- 근거: 사용자 결정(2026-10-06), 저장소 참조 구현 `feat/v169-usage-examples` 브랜치 PR
- 요지
  - '활용 사례'를 '활용 예시'로 변경함
  - '활용 예시' 제목 옆에 'AI 생성' 표시를 붙임
  - 내용·건수·배치·접힘 동작은 변경하지 않음

## 1. 변경 내용

| 항목 | 현행 | 변경 |
|---|---|---|
| 접힘 제목 | 활용 사례 N건 | 활용 예시 N건 |
| 표시 | 없음 | 제목 오른쪽에 'AI 생성' 표시 |
| 프레임워크 워크북 열 이름(화면 표기 기준) | 활용 사례 | 활용 예시 |

- 'AI 생성' 표시
  - 문구: 'AI 생성'(다른 문구·설명문 추가하지 않음)
  - 위치: 접힘 제목과 같은 줄, 제목 바로 오른쪽. 접힌 상태에서도 보임
  - 형태: 작은 알약형 표시. 경고색(주황·빨강)을 쓰지 않음(참조 구현: 글자 #33507a, 바탕 #eaf0f8, 테두리 #cbd8ea)
  - 화면 폭이 좁으면 제목 아래 줄로 내려감. 가로 넘침 없음(320~1920px)
- 적용 범위: 활용 예시가 있는 모든 데이터·모든 국가

## 2. 변경하지 않음

- 각 예시의 구성(목적·논리 구조·쓰는 데이터·스토리라인·주 사용자·유의점), 순서, 건수
- 개별 예시의 '검증 대기' 표시
- E-020 '지원제도와 활용 사례': 지원제도별 실제 수행 기록(원자료)이므로 명칭 유지

## 3. 검수 기준

- 상세 화면 어디에도 '활용 사례 N건' 문구가 없음(E-020 원자료 기록 제외)
- '활용 예시 N건' 옆에 'AI 생성' 표시가 보임
- 6폭(320·390·768·1024·1440·1920px) 가로 넘침 0
