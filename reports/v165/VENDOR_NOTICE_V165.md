# 국가 선택 화면 변경 통보(V165)

- 수신: 플랫폼 화면 개발 용역사
- 대상: 개도국 기후기술 협력 플랫폼(공개 2개국 → 최대 10개국)
- 근거
  - 「국가 선택 UI 기획(10개국 확장)」(2026-10-05)
  - 저장소 참조 구현: `feat/v165-country-picker` 브랜치 PR
- 요지
  - 국가 선택 방식을 부품 1개로 통일하고, 공개 국가 수에 따라 형태가 자동으로 바뀌도록 변경함
  - 화면 구조·URL·데이터 경로는 변경하지 않음. 아래 범위만 반영함

## 1. 변경 범위

| 구분 | 내용 |
|---|---|
| 신설 부품 | 국가 선택 부품 1개(헤더·홈·이용안내 공용) |
| 레지스트리 필드 | `public/data/countries.json`에 2개 추가: 최상위 `regions`, 국가별 `region` |
| 적용 위치 | 7곳(2절) |
| 변경 없음 | 화면 5개·상단 메뉴 구성, URL `?country=ISO3`, 데이터 경로 `/data/<국가>/v2`, 화면별 레이아웃 |

## 2. 적용 위치(7곳)

| 위치 | 현행 | 변경 |
|---|---|---|
| 헤더(전 화면) | 국가 표시 없음 | 상단 메뉴 오른쪽·검색 왼쪽에 '국가명 ▾' 버튼 신설 |
| 홈 | 문장형 링크('현재 제공 국가 · 베트남 · 방글라데시', 누르면 전체 새로 고침) | 부품으로 교체('국가' + 국가별 전환 버튼, 새로 고침 없음) |
| 데이터 이용안내 | 홈과 같은 문장형 링크 | 부품으로 교체(홈과 동일) |
| 데이터 찾기 | 드롭다운('전체' 포함) | 유지. 공개 5개국 이상이면 권역별 `optgroup` |
| 데이터 다운로드 | 드롭다운('전체' 포함) | 유지(위와 같음). 페이지에서 바꾼 국가를 주소·헤더에 반영 |
| 상세(2곳) | 드롭다운 | 유지(위와 같음) |
| 데이터 지도 | 드롭다운 | 유지(위와 같음) |

## 3. 표시 규칙(공개 국가 수 기준, 코드 수정 없이 자동 전환)

| 공개 국가 수(`status: "live"`) | 헤더 | 홈·이용안내 | 페이지 드롭다운 |
|---|---|---|---|
| 1개국 | 국가명만 표시 | 국가명만 표시 | 1개 항목 |
| 2~4개국 | 버튼 + 목록 | 국가별 전환 버튼(선택 국가 강조, 항목 수 표시) | 평면 목록 |
| 5~10개국 | 버튼 + 권역별 목록 | 버튼 + 권역별 목록(헤더와 동일) | 권역별 `optgroup` |
| 목록 11개국 이상 | 목록 위 검색창 추가 | 같음 | 같음 |

- 목록 대상: 공개(`live`) + 공개 예정(`preparing`) 국가
  - 공개 예정 국가: 회색 '공개 예정', 선택 불가
  - 페이지 드롭다운: 공개 국가만
- 권역 묶음: 목록 5개국 이상일 때. 권역 순서는 `regions[].order`, 권역 안은 한글 국가명 가나다순
- 권역이 없는 국가: 목록 맨 아래 '기타'
- 국가명·국가 수·권역명은 화면 코드에 쓰지 않음. 모두 레지스트리에서 읽음

## 4. 레지스트리 필드

```json
"regions": [
  { "key": "sea", "nameKo": "동남아시아", "order": 1 },
  { "key": "sa", "nameKo": "남아시아", "order": 2 },
  { "key": "mena", "nameKo": "중동·북아프리카", "order": 3 }
],
"countries": [ { "iso3": "VNM", "...": "...", "status": "live", "region": "sea" } ]
```

- 10개국 권역: 동남아시아 6(라오스·말레이시아·베트남·인도네시아·캄보디아·필리핀) · 남아시아 3(방글라데시·스리랑카·인도) · 중동·북아프리카 1(이집트)
- 국가 추가 시 해당 국가 항목에 `region`만 기재함
- 항목 수('146개 항목')는 레지스트리에 기재하지 않음. 부품이 각 국가 카탈로그에서 실행 시 계산함(홈 '전체 데이터 항목'과 같은 값)

## 5. 동작 규칙

- 헤더에서 국가를 바꾸면 현재 화면을 유지하고 그 화면의 국가만 바꿈

| 화면 | 헤더에서 국가 변경 시 |
|---|---|
| 홈·이용안내 | 같은 화면을 새 국가로 다시 표시(주소 `?country=`, 기본 국가는 생략) |
| 데이터 찾기 | 국가 필터를 새 국가로 변경, 다른 필터 유지 |
| 데이터 다운로드 | 국가 선택을 새 국가로 변경, 선택 항목 초기화 |
| 상세 | 같은 항목을 새 국가로 표시(페이지 드롭다운과 동일) |
| 데이터 지도 | 새 국가로 전환, 켠 레이어·선택·비교 해제, 전체 범위로 이동(페이지 드롭다운과 동일) |

- 데이터 찾기·다운로드에서 '전체'를 고른 동안: 헤더는 마지막 국가를 표시. 헤더에서 그 국가를 고르면 해당 국가로 적용
- 페이지 드롭다운으로 바꾼 국가도 헤더·주소에 즉시 반영
- 브라우저 뒤로 가기: 이전 국가로 복원
- 화면 이동(메뉴) 시 국가 유지
- 국가 레지스트리를 읽기 전에는 국가명을 표시하지 않음(자리만 확보). 국가 코드(VNM 등) 노출 금지
- 빠른 연속 전환 시 마지막 선택을 적용

## 6. 접근성·크기

| 항목 | 기준 |
|---|---|
| 누르는 영역 | 데스크톱 높이 32px 이상, 768px 이하 44px 이상 |
| 전환 버튼(2~4개국) | `role="radiogroup"`/`radio`, ←/→로 이동·선택, 다시 그린 뒤에도 선택 버튼에 초점 유지 |
| 목록 버튼 | `aria-haspopup="listbox"`, `aria-expanded`, 화면 낭독 이름 '국가 선택, 현재 ○○' |
| 목록 | `role="listbox"`·`option`·권역 `group`, Enter·Space·↓로 열기, ↑↓·Home·End 이동, Enter 선택, Esc 닫기(초점 복귀), 글자 입력 시 해당 국가로 이동, 바깥 누르면 닫기 |
| 768px 이하 | 헤더 아래 전체 폭 목록. 560px 이하에서는 국가 버튼이 메뉴 줄 맨 앞으로 이동(헤더 높이 현행 유지) |
| 감사 표식 | 부품 최상위에 `data-country-picker="true"`·`data-country-selector="v162"` 유지(통합 인수 게이트가 읽음) |
