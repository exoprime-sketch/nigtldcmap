## V165 — 국가 선택 부품 통일(10개국 확장 대비) 참조 구현

사용자 지시(2026-10-05 07:14·07:26): 10개국까지 확장 가능한 국가 선택을 유사 플랫폼 벤치마킹으로 기획하고, 용역사 작업을 크게 바꾸지 않는 범위에서 진행. 본 PR은 저장소 참조 구현이고, 용역사에는 변경분을 통보함.

- 상세 보고: `reports/v165/REVIEW_V165.md`
- 용역사 통보문: `reports/v165/VENDOR_NOTICE_V165.md`
- 기획 문서: 「국가 선택 UI 기획(10개국 확장)」

### 바뀐 것
- **국가 선택 부품 1개 신설**: 공개 국가 수에 따라 형태 자동 전환
  - 1개국: 이름만
  - 2~4개국: 홈·이용안내는 국가별 전환 버튼, 헤더는 버튼 + 목록
  - 5개국 이상: 권역별 목록
  - 목록 11개국 이상: 검색창
  - 공개 예정 국가는 회색 '공개 예정', 선택 불가
- **레지스트리 필드 2개**: `countries.json`에 `regions`(최상위)·`region`(국가별). 항목 수는 실행 시 각 국가 카탈로그에서 계산
- **적용 7곳**
  - 헤더(신설): 메뉴 오른쪽·검색 왼쪽 '베트남 ▾'
  - 홈·이용안내: 문장형 링크(누르면 전체 새로 고침) → 전환 버튼(새로 고침 없음)
  - 찾기·다운로드·상세 2곳·지도: 드롭다운 유지, 공개 5개국 이상이면 권역 `optgroup`
- **동작**
  - 헤더에서 바꾼 국가가 현재 화면에 바로 반영. 화면은 그대로
  - 뒤로 가기로 복원, 메뉴 이동 시 유지
  - 찾기·다운로드 '전체' 중에는 헤더가 마지막 국가 표시
  - 다운로드 드롭다운 변경을 주소·헤더에 반영
- **지운 것**: `CountryScopeLinksV162`(문장형 링크)
- 변경 없음: 화면 5개·상단 메뉴, URL `?country=`, 데이터 경로, 화면 레이아웃, 데이터
