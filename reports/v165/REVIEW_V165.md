## 2. 바뀐 것

### 2-1. 부품과 규칙

- `countryPickerModelV165.ts`(순수 함수): 레지스트리 → 형태 판단
  - 공개 ≤1 → `single` / 홈·이용안내에서 공개 2~4 → `segmented` / 그 밖 → `list`
  - 목록 = 공개 + 공개 예정. 5개국 이상이면 권역별 묶음(권역 `order`, 권역 안 가나다순), 권역 미기재 국가는 '기타'(맨 아래)
  - 목록 11개국 이상이면 검색창. 한글·영문 이름·코드로 검색
  - 페이지 드롭다운: 공개 5개국 이상이면 권역 `optgroup`(`countrySelectGroupsV165`)
- `CountryPickerV165.tsx`: 헤더(`header`)·홈·이용안내(`inline`) 공용
  - 전환 버튼: `radiogroup`/`radio`, ←/→ 이동, 국가별 항목 수(홈 '전체 데이터 항목'과 같은 값) 표시
  - 목록: 버튼 `aria-haspopup="listbox"` + `listbox`/`option`/권역 `group`, ↑↓·Home·End·Enter·Esc·글자 입력 이동, 바깥 누르면 닫힘, 닫으면 버튼으로 초점 복귀
  - 공개 예정 국가: 회색 '공개 예정', `aria-disabled`, 선택 불가
  - 레지스트리를 읽기 전에는 자리만 확보(번들 기본값은 국가명을 코드로 갖고 있어 'VNM' 노출 방지)
  - 최상위에 `data-country-picker`·`data-country-selector="v162"` 유지(통합 인수 게이트·국명 감사가 읽는 표식)
- `CountryOptionsV165.tsx`: 페이지 드롭다운 4곳(찾기·다운로드·상세 2·지도)의 항목 렌더링 통일
- `useCountryRegistryV165.ts`: 레지스트리 읽기(읽기 전 `null`)
