## 사용자 화면의 변경

### 상세보기

- 지도에 실제 연결된 **42개 항목**에 작은 지도를 추가했다. 시설은 점, 송전망은 선, 지역 통계는 실제 성·시 경계로 표시한다.
- 상세 분석 다음에 지도를 배치했다. 항목·기준시점 변경, 지역·시설 목록 선택, 선택 대상의 핵심 값과 출처, `큰 지도에서 비교`를 제공한다.
- 큰 지도와 같은 원자료·제외 규칙·발전소 출처 필터를 사용한다. 미제공 값은 0으로 바꾸지 않는다.
- 작은 지도에서 고른 지도 항목·기간을 큰 지도에 전달한다. 상세의 특정 지표가 지도에 없으면 임의로 같은 지표처럼 보이게 하지 않고, 지도에 제공되는 대체 항목과 안내를 표시한다.
- 작은 지도는 지연 로딩 SVG로 그린다. 상세마다 MapLibre 지도 엔진을 추가로 실행하지 않는다.
- 발전소는 출처별 발전원 구성에 대해 **설비용량 비교 + 시설 수 비교 + 시설 목록 + 위치 지도**를 제공한다. WRI와 OSM을 합쳐 국가 전체 용량처럼 집계하지 않는다.
- 송전망은 **전압별 선로 길이 + 구간 수 + 경로**를 보여주고 2016년 선로와 PDP8 계획을 구분한다.
- 기후·자원·산림 자료는 기존 추이·지역 분석에 같은 시점/시나리오의 지역 비교와 작은 지도를 연결한다. 태양광·풍력 장기평균의 기준기간도 표시한다.
- 현재 선택 항목과 관계없는 범용 분류 선택지가 빈 결과를 만드는 문제를 줄였다. 문장형 값의 불필요한 `단위 미기재` 표기를 제거했다.

### 지도 팝업·오른쪽 패널

- 검사 용도의 숨김 문구가 팝업에 노출되던 문제를 수정했다. 시설명·발전원·설비용량·출처/연도가 같은 문장으로 반복되지 않는다.
- 겹침은 주 분석 자료를 우선하고 함께 켠 자료는 뒤에 배치한다. 이 순서와 수치 표시는 단위 테스트로 확인했다.
- 발전소, 광산, CCS, 관측소, 사업, 기관, 기업별로 필요한 속성을 우선 배치한다. 내부 키·좌표 처리 코드·분류용 보조 필드는 공개 핵심 정보에서 제외한다.
- 선택 지역의 출처는 그 값의 지표에서 읽는다. 관련 없는 기관 목록을 선택 값의 출처로 나열하지 않는다.
- 수문자료는 관측값마다 시점을 붙인다. 서로 다른 연도의 건기·우기 값을 같은 해 비율로 다시 계산하지 않는다.
- 적응기금은 다국가 사업 전체 승인액과 베트남 단독 사업액을 혼동하지 않도록 표시한다.
- 탄소사업은 확인된 등록제도·등록번호·원문, 기관은 소재 도시·주요 업무/전문 분야, 기업은 기술 분야·진출 형태·상태를 제공한다. 원자료에 없는 값은 새로 만들지 않는다.
- 오른쪽은 선택 대상 정보와 현재 표시 자료 요약을 구분한다. 발전소 출처별 용량·시설 수, 지역자료의 선택 지역 추이 등 실제 분석에 필요한 정보를 제공하고 자료 범위 설명은 접을 수 있게 했다.

## 벤치마킹 근거

`detail-and-map-review-152-v148.md`에 152개 각각의 사용자 질문, 분석 구성, 해석 원칙, 두 개 이상의 참고 사례를 연결했다. 30개 공식 자료·서비스를 유형별로 비교한 것이며, 152개의 서로 다른 사이트를 조사했다는 뜻은 아니다.

주요 참고 방식:

- IEA / IRENA: 에너지 절대량·구성·기술별 단위 비용.
- World Bank CCKP / Copernicus: 지역·시나리오·기간의 일관된 연결.
- Global Forest Watch / FAO FRA: 산림의 정의·분류·기간을 구분한 변화 분석.
- GEM / WRI 발전소 DB: 시설명·발전원·용량·원천 범위.
- OECD / GCF / World Bank Projects: 사업·공여자·분야·금액·진행 상태.
- IEA Policies / Climate Change Laws: 문서·관할·시행시점·원문.
- 공공데이터포털: 검색조건·제공기관·자료기간·다운로드의 공공 서비스 문구.

정책·기관·문장형 자료에는 숫자 차트를 강제하지 않는다. 문서 연대기, 비교표, 역할·소재지·공식 원문 목록이 더 적합한 경우 이를 유지했다.

6. 전체 필터 조합, 모든 개별 시설, Linux 시각 baseline, 원격 Preview/Production, 이번 후보의 전체 `finalize` 게이트는 실행하지 않았다. 로컬 검증과 배포 검증을 구분한다.
