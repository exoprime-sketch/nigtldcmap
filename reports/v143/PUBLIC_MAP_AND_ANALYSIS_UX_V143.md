## 2. 상세 분석

### 사업·재원·기업형: 17개

- 기존에는 검색·연도·분야 선택이 목록에만 적용됐다. 이제 같은 조건이 건수, 금액, 추이, 분류별 구성과 목록에 함께 적용된다.
- 3개 이상 연도가 있는 자료는 연도별 건수 추이를 선 차트로 제공한다. 기간 확대·축소 및 전체 기간 복원이 가능하다.
- 모든 추이·구성에 표 전환을 제공한다. 분야별 차트는 상위 8개를 먼저 보여 주고 전체 항목을 펼칠 수 있다. 구성비 분모는 표시된 8개가 아니라 전체 분류 건수다.
- 단일연도는 단면값으로, 연도 없는 기업·제도 자료는 유형별 구성으로 제공한다. 없는 연도를 0으로 채우거나 임의 시계열을 만들지 않는다.
- 통화별 합산, 승인액/약정액 구분, 집계·유형 설명 행 제외 등 기존 원자료 규칙을 유지한다.
- 필터 변경 시 목록 페이지를 초기화하고, 검색 결과가 없으면 차트 대신 안내한다.
- 빈 선택기 띠와 중복된 내부 제목을 줄였다. 용어 설명 버튼에 일반 작업 버튼 스타일이 번지지 않도록 범위를 제한했다.

확인 예: D-015 2024년 선택 → 25건, 약정액 2.66억 USD, 구성 및 목록 25건. D-026 `Hoi Xuan` 검색 → 사업 1건, 보증금액 2.4억 USD, 회계연도 2016; 유형 설명 5건은 사업 집계에서 제외한다.

## 4. 완료 판정 전에 남은 일

1. **원자료의 집계 단위 확인:** D-015에는 같은 제목에 서로 다른 보고기간이 붙은 행이 있다. 현재는 기존 원자료 개별 행 집계를 유지했다. ‘고유한 사업 수’를 제공하려면 사업 식별자의 관계와 보고기간 분할을 검토해야 하며, 제목 유사성만으로 중복 삭제하면 안 된다.
2. **나머지 자료형의 실사용 검토:** 법·제도는 적용대상/시행일/핵심조건 비교, 기관은 분야/지역/지원업무 탐색, 논문·특허는 연도/분야/기관 분석을 각각 점검한다. 숫자가 없는 문서에 파이차트나 의미 없는 건수 추이를 추가하지 않는다. 이번 152개 로딩 검사를 그 검토의 대체 근거로 삼지 않는다.
3. **공간자료 부족:** B-017 평가구역 및 B-023/B-025/B-028 유역 경계 미확보 상태는 유지한다. 없는 경계를 임의로 만들지 않았다.
4. **배포 검증:** 승인 후 하나의 고정된 커밋·빌드로 전체 release gate와 Linux E2E를 실행하고, 동일 SHA의 Preview에서 영향을 받은 화면을 확인한다. 전체 `finalize:v140`, Linux 시각 baseline, Preview·Production 검증은 이번 턴에서 실행하지 않았다.
5. **한국어 최종 감수:** 용어·길이·중복 문장을 다듬되 값의 의미·연도·단위·대상 범위는 유지한다. 새 탭 없이 기존 화면의 수용 여부를 결정한다.
