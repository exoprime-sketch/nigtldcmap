# '데이터 찾기' 검색 결과 개선 기준(V170)

국가녹색기술연구소 · 2026-10-07

| 순서 | 영역 | 표시 조건 |
|---|---|---|
| 1 | 검색창 | 항상 |
| 2 | 함께 찾은 말(④) | 검색어가 동의어 사전 그룹에 해당할 때 |

| 4 | 핵심 데이터 패널(①) | 국가 1개 선택 + 주제어 검색 + 다른 필터 없음 |

- 검색어가 없을 때의 목록·정렬(가나다순 기본)·카드는 현행과 같음

## 2. 기능 규칙

### ① 핵심 데이터 패널

- 표시 조건: 국가 1개 선택, 검색어가 주제 사전(10개 주제)에 해당, 다른 필터(대분류·그룹·기관·기술·연도·제공 형태·사용자·유형)가 모두 '전체'
- 제목: '{주제} 핵심 데이터 · {국가명}', 부제: '{N}개 데이터에서 {주제} 관련 수치만 모아 보기'
- 행 구성: 역할 | 데이터명·제공기관 | 값·보조 문구(3개 연도 이상이면 추이 소형 그래프) | 상세보기·지도에서 보기
- 값은 화면에서 계산하지 않음. 빌드 단계에서 원자료로 계산한 `public/data/search/v170/topics-<ISO3>.json`을 그대로 표시함
- 계산 방식(4종)
  - 카드 대표값: 대표값 문구에 조건어가 있을 때만 사용
  - 지표 최신값: 지표 1개의 최신 연도 값. 여러 지표는 합산하지 않음
  - 시설 집계: 주연료가 주제어인 시설 수·용량 합계(예: 태양광 발전소 16곳 · 1,616 MW)
  - 원자료 기록 수: 주제어(동의어 포함)가 들어간 기록 수(예: 태양광 관련 22건 / 56건 중)
- 값이 없는 행은 빠짐. 3행 미만인 주제는 패널을 표시하지 않음. 추정값·임의값으로 채우지 않음
- 지역명은 기존 지역명 표기 규칙('한글(현지명)')을 따름
- 하단 주석: '수치는 각 데이터의 원자료로 계산한 값입니다'

### ② 관련도순 정렬과 묶음

- 검색어를 입력하면 정렬 기본값이 '관련도순'(정렬 목록 첫 항목). 검색어가 없으면 '관련도순'은 비활성
- 가나다순·조회순을 고르면 그 순서로 정렬하고, 묶음 버튼은 그대로 유지함
- 묶음 판정(데이터별)
  - ‘{검색어}’에 관한 데이터: 이름·자료명·정의·설명·활용 방법·분류·제공기관·국가에 검색어가 있음
  - ‘{검색어}’ 내용이 포함된 데이터: 위에는 없고 데이터 안의 개별 내용(원자료 기록)에만 있음
  - ‘{검색어}’ 기술로 분류된 데이터: 기후기술 분류 이름에만 있음
- 묶음 이름은 데이터가 검색어와 어떻게 관련되는지를 말하며, 검색어를 작은따옴표(‘ ’)로 감싸 넣음. 검색어 뒤의 말('에 관한', ' 내용이 포함된', ' 기술로 분류된')은 고정이므로 받침에 따라 바꾸지 않음
- 검색어가 여러 단어면 모든 단어가 있어야 결과에 포함(AND). 묶음은 가장 약하게 일치한 단어 기준
- 제공기관·국가는 입력한 단어로만 비교함(동의어 확장 안 함). 예: '태양광' 검색 시 제공기관 'Global Solar Atlas'는 일치로 보지 않음
- 묶음 안 순서: 아래 점수 높은 순 → 같은 점수는 가나다순. '데이터 준비 중' 데이터는 묶음 안에서 마지막

| 일치 위치 | 점수 |
|---|---|
| 이름 | 1,000 + 400 + 원자료 일치 비율 × 100 |
| 자료명 | 1,000 + 380 + 비율 × 100 |
| 정의 | 1,000 + 300 + 비율 × 100 |
| 설명 | 1,000 + 260(카탈로그) 또는 250(명세서) + 비율 × 100 |
| 활용 방법 | 1,000 + 200 + 비율 × 100 |
| 분류 / 제공기관 / 국가 | 1,000 + 150 / 120 / 50 + 비율 × 100 |
| 내용(원자료 기록)에만 있음 | 500 + 비율 × 400 + log₁₀(일치 건수 + 1) × 20(최대 50) |
| 기후기술 분류에만 있음 | 100 |

- 묶음 버튼: '‘{검색어}’ 관련 데이터 N개' + 전체 / ‘{검색어}’에 관한 데이터 / ‘{검색어}’ 내용이 포함된 데이터 / ‘{검색어}’ 기술로 분류된 데이터(각 건수). 0건 묶음은 비활성
- 관련도순 '전체' 보기에서는 묶음마다 제목('{묶음명} N개' + 설명 한 줄)을 붙임
  - 설명: '데이터 이름이나 설명이 이 주제를 다룹니다' / '데이터 안의 일부 내용에 검색어가 있습니다(포함 비율이 높은 순)' / '기후기술 분류만 해당하고, 데이터 내용에는 검색어가 없습니다'
- '‘{검색어}’ 기술로 분류된 데이터'는 접어 두고 '펼치기' 버튼으로 엶. 펼친 뒤 '접기' 버튼 제공

### ③ 일치 근거(카드 하단, 버튼 위)

- 1행
  - ‘{검색어}’에 관한 데이터: '{위치}에 ‘{검색어}’ 포함'(예: 설명에 ‘태양광’ 포함). 내용에도 있으면 '내용 N건 중 M건에도 포함' 덧붙임
  - ‘{검색어}’ 내용이 포함된 데이터: '내용 N건 중 M건에 ‘{검색어}’ 포함'
- 2행: 첫 일치 문구 앞뒤 28자, 검색어 강조(노란 배경)
- 이름에 있는 경우 2행 생략(카드 제목과 중복)
- ‘{검색어}’ 기술로 분류된 데이터: 1행 없이 '기후기술 분류에만 ‘{검색어}’ 관련 기술이 있고, 데이터 내용에는 검색어가 없습니다'
- 원자료 문구는 공개용으로 정제한 검색 자산(`records-<ISO3>.json`)에서만 가져옴. 내부 키·코드·파일명·링크·이메일·작업 메모·빈값 표기('미확인' 등)는 넣지 않음

### ④ 함께 찾은 말(동의어 확장)

- 검색창 아래 '함께 찾은 말' 줄에 함께 검색한 말을 표시
- 동의어 사전: `src/data/search/searchSynonymsV170.json`(46개 그룹: 기후기술 32개 + 기후위험·재원 등 14개)
- 확장 규칙
  - 같은 그룹의 말은 서로 같은 뜻으로 보고 양방향으로 함께 검색
  - 상위·하위 개념은 확장하지 않음(재생에너지 ⊃ 태양광)
  - 한글은 단어 안에서도 찾고 띄어쓰기를 무시함(태양광 발전 = 태양광발전)
  - 영문·약어는 단어 단위로만 찾음(PV는 PVC를 찾지 않음), 대소문자 무시
  - 사전에 있는 띄어 쓴 말('solar PV', '해수면 상승')은 한 단어로 처리

## 3. 관련 파일

| 파일 | 용도 | 비고 |
|---|---|---|
| `src/data/search/searchSynonymsV170.json` | 동의어 사전(화면이 읽는 파일) | 기준본은 엑셀. 엑셀에서 변환 |
| `검색사전_20261007.xlsx` | 동의어 사전 편집본 + 핵심 데이터 규칙(국가별 현재 값) | `python3 scripts/v170/search-dictionary-xlsx-v170.py export` |
| `scripts/v170/topic-rules-v170.json` | 핵심 데이터 패널 규칙(10개 주제) | |
| `scripts/v170/build-search-v170.mjs` | 검색 자산 생성(원자료 → records·topics) | 국가 추가·데이터 갱신 시 재실행 |
| `public/data/search/v170/*.json` | 검색 자산(국가별 2개) | 전달하지 않음. NAS 최신 데이터로 위 스크립트를 실행해 생성 |
| `src/data/search/searchMatchV170.ts` | 일치·묶음·점수 규칙(참조 구현) | 단위 시험 `searchMatchV170.test.ts` |
| `reports/v170/screens/` | 변경 전후 화면 캡처(본 기준서 5장에 주요 화면 수록) | 태양광(solar)·풍력(wind)·홍수(flood), 베트남 |

- 사전 갱신 절차: 엑셀 수정 → `search-dictionary-xlsx-v170.py import <파일> --check` → `import <파일>` → `node scripts/v170/build-search-v170.mjs` → `npm run test:unit`
- 국가 추가·원자료 갱신 시: `build-search-v170.mjs`가 `public/data/countries.json`의 공개(live) 국가를 모두 다시 생성함
- `build-search-v170.mjs`는 참조 구현의 데이터 묶음(packs) 구조를 읽음. 용역사 시스템의 데이터 구조가 다르면 읽기 부분만 맞추고, 정제·계산 규칙과 `topic-rules-v170.json`은 그대로 사용
- 기존 전문 검색 색인(`search-index-v124`)은 '데이터 찾기' 검색에 쓰지 않음(작업 메모가 섞여 있어 공개 화면 근거로 부적합)

- 위 건수는 참조 구현에 탑재된 데이터 기준이며, NAS 최신 데이터로 검색 자산을 다시 생성하면 달라질 수 있음. 판정은 같은 데이터로 생성한 `topics-<ISO3>.json`·`records-<ISO3>.json`과 화면이 일치하는지로 함
- 10개 주제 × 2개국(베트남·방글라데시) 패널 행이 `topics-<ISO3>.json`과 일치
- '전체' 국가 검색: 패널 없음, 묶음 정상
- 일치 근거에 내부 코드·작업 메모·파일명 0건
- 6폭(320·390·768·1024·1440·1920px) 가로 넘침 0
- 단위 시험 `searchMatchV170.test.ts` 통과(패널의 '관련 N건'과 카드의 '내용 N건 중 M건'이 같은 계산임을 확인)
