# 우선 협력 10개국 표시 변경 통보(V166, V165 통보 추가분)

- 수신: 플랫폼 화면 개발 용역사
- 대상: 개도국 기후기술 협력 플랫폼(공개 2개국 · 공개 예정 8개국)
- 근거
  - 「10개국 노출 기획」(2026-10-05)
  - 저장소 참조 구현: `feat/v166-ten-countries` 브랜치 PR
  - 「국가 선택 화면 변경 통보(V165)」의 추가분
- 요지
  - 우선 협력 10개국을 헤더·홈·이용안내에 모두 표시함
  - 데이터가 공개된 국가만 선택 가능. 나머지는 이름·권역·'공개 예정'만 표시하고 숫자는 표시하지 않음
  - 국가 선택 부품에서 항목 수 표시를 삭제하고, 홈 하단으로 데이터 현황 줄을 옮김
  - 새 화면·새 주소·상단 메뉴 변경 없음. 데이터 값 변경 없음

## 1. 화면 변경(4곳 + 표시 규칙 2가지)

| 위치 | 현행(V165) | 변경 |
|---|---|---|
| 헤더 국가 목록 | 공개 2개국 | 레지스트리 10개국을 권역 3개로 묶어 표시. 공개 예정 8개국은 회색 '공개 예정', 선택 불가. 목록 최대 높이 600px |
| 홈 '국가' | 공개 국가 전환 버튼 | '권역 줄': 권역별 한 줄. 공개 국가는 전환 버튼, 공개 예정 국가는 같은 줄에 '·'로 잇는 회색 이름 + '공개 예정' 표시(버튼 아님) |
| 데이터 이용안내 '데이터 제공 범위' | 현재 국가 문장 | 같은 절 안에 '제공 국가' 표(권역·국가·상태·제공 내용) + 안내 1줄. 제공 내용은 공개 국가만 '데이터 항목 N개'(카탈로그에서 계산), 공개 예정은 '—' |
| 공개 예정 국가 주소(`?country=PHL` 등) | 안내 없이 기본 국가 표시 | 기본 국가를 표시하고 본문 위에 안내 1줄: '{국가명} 데이터는 공개 예정입니다. 지금은 {공개 국가명} 데이터를 볼 수 있습니다.' 국가를 고르거나 메뉴를 옮기면 사라짐. 지도 화면에는 표시하지 않음 |
| 국가 선택 부품(헤더·홈·이용안내) | 공개 국가 옆에 항목 수 | 항목 수 삭제(국가명만) |
| 홈 데이터 현황 줄 | 첫 화면 바로 아래 띠 | 홈 맨 아래 작은 글씨 한 줄로 이동. 항목 4개(전체 데이터 항목·지도 제공 항목·다운로드 가능 항목·데이터 기준일)와 클래스는 그대로 |

- 변경 없음: 데이터 찾기·다운로드·상세·지도의 국가 드롭다운(공개 국가만), 화면 5개·상단 메뉴, URL, 데이터 경로

## 2. 표시 규칙 보완(V165 3절 갱신)

| 구분 | 규칙 |
|---|---|
| 홈 '국가'(`overview`) | 공개 1개국 이상 + 공개 예정 국가가 있고 목록이 12개국 이하: 권역 줄(5개국부터 권역 이름 표시). 13개국 이상: 헤더와 같은 버튼 + 목록. 공개 예정 국가가 없으면 V165와 같음 |
| 이용안내 위 '국가' | V165와 같음(공개 국가 전환 버튼). 10개국 전체는 '제공 국가' 표가 표시 |
| 권역 안 순서 | 공개 국가 먼저, 그다음 한글 국가명 가나다순(헤더·홈·이용안내 공통) |
| 모바일(560px 이하) 홈 | '국가' 글자는 화면 읽기 전용, 권역 이름·버튼·국가명이 한 흐름으로 줄바꿈 |
| 키보드 | 홈 권역 줄의 ←/→는 공개 국가 사이만 이동. 공개 예정 이름은 초점 이동 대상이 아님 |

## 3. 레지스트리(`public/data/countries.json`)

- 8행 추가. 공개 예정 행은 5개 필드만 둠

```json
{ "iso3": "PHL", "nameKo": "필리핀", "nameEn": "Philippines", "region": "sea", "status": "preparing" }
```

- 대상: PHL·KHM·IDN·LAO·MYS(동남아시아), LKA·IND(남아시아), EGY(중동·북아프리카)
- 데이터 필드(`dataRoot`·`adm`·`bbox`·`defaultZoom`·`boundaryEpoch`·`categoriesAvailable`)는 공개로 바꿀 때 납품 자료에서 채움
- 행 형식: 데이터 필드가 있는 행 | 이름만 있는 공개 예정 행. 데이터 필드를 읽는 코드는 `hasCountryDataV166`·`liveRegistryCountriesV166`로 확인한 뒤 읽음

## 4. 함께 반영할 내부 수정(참조 구현 코드 그대로 반영)

| 대상 | 수정 | 미반영 시 |
|---|---|---|
| 국가 데이터 공급자 등록 | 데이터 필드가 있는 행만 등록 | 공개 예정 행에서 화면 전체 오류 |
| 레지스트리 형식 | 공개/공개 예정 두 형식(3절) | 데이터 필드 누락을 실행 중에야 발견 |
| 용어 사전 국가 표시 | 국가 범위 = 공개 국가 | 인도·인도네시아 등을 언급한 용어가 베트남·방글라데시 화면에서 사라짐 |
| 빌드·검사 스크립트 | 데이터 트리를 읽는 곳은 데이터 필드가 있는 행만 | 없는 경로를 읽어 검사 실패 |
| 인수 검사 '다른 나라 이름' | 대상 = 데이터가 있는 나라 | 그 나라 자료의 이웃 나라 언급(ASEAN 회원국 등)을 오류로 판정 |

## 5. 공개 전환 절차(국가당)

1. 데이터 납품 → 국가 ETL·입고 검사
2. 레지스트리 해당 행에 데이터 필드를 채우고 `status`를 `live`로 변경
3. 바뀐 나라만 필터 검사 후 PR
- 화면 코드 변경 없음. 헤더·홈·이용안내·드롭다운·데이터 현황 줄에 자동 반영

## 6. 검수 기준

- 헤더 목록 10개국·3권역, 공개 예정 8개 선택 불가
- 홈 권역 줄·이용안내 표의 국가·상태가 레지스트리와 일치. 숫자는 공개 국가만
- `?country=<공개 예정>`: 기본 국가 + 안내 1줄, 콘솔 오류 0
- 공개 예정 국가의 항목 수·공개일·진행률 표시 0
- 6폭(320·390·768·1024·1440·1920px) 가로 넘침 0, 헤더 높이 현행 유지
