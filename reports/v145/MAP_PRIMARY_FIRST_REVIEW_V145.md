## 변경한 표시 규칙

1. 겹침 팝업 첫 부분에 주 분석 데이터명, 값·단위, 지역, 선택 지표·기간을 표시한다.
2. 그 아래에 함께 보는 데이터명과 해당 시설·선로·지역의 정보를 표시한다.
3. 송전망은 전압·선로 길이, 발전소는 설비용량·발전원·자료연도를 사용한다. 기관·사업은 원자료의 유효한 속성을 사용하며 숫자를 만들지 않는다.
4. 실제 포인터 위치에 주 분석 객체가 없으면 주 분석 값을 다른 지역이나 전국 합계에서 가져오지 않는다.
5. 최근 클릭한 보조 자료가 있어도 주 분석을 맨 위에 표시한다. 클릭 목록도 동일한 모델을 사용한다.
6. 팝업에는 최대 세 항목을 보여주고 나머지는 클릭 목록에서 모두 선택할 수 있다. 같은 자료의 서로 다른 선로를 하나로 합산하지 않는다.
7. 결측은 0으로 바꾸지 않으며 실제 0은 그대로 표시한다. 기간·필터·주 분석이 바뀌면 이전 팝업과 선택 목록을 닫는다.
8. `adm1Name`, `value` 등의 내부 필드와 전압·길이의 중복 표시를 제거했다. 숫자 단위의 기존 용어 안내는 유지했다.
9. 지도 캔버스 내부의 팝업이 범례 뒤에 갇히던 표시 순서를 수정했다. 읽기 전용 팝업은 포인터 조작을 가로채지 않는다.
