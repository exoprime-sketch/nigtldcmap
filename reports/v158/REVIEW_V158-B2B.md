## 요약
- 베트남 화면은 그대로 두고(화면 변화 0), 방글라데시 같은 비기본 국가를 레지스트리만으로 화면에 올릴 수 있는 계층을 넣었다. BGD는 `preparing` 그대로라 공개 화면에는 나오지 않는다.
- 10개국 확장 기준(사용자 2026-09-29)을 코드·점검으로 옮겼다: 국가 고유 12요소 이름·출처, 타국 문구 숨김(원문 무수정), 괄호 로마자, 벵골 글꼴, 비교 연도 규칙, 레지스트리만, QA 3종.
- 실행 성공과 내용 완성을 구분한다: BGD 화면은 레지스트리를 브라우저 안에서만 live로 바꿔 검사했다(파일 미변경). BGD 공개·지도 등록은 PR-C·PR-D.

## 변경
### 국가별 로더·provider
- `countryDataLoaderV158`: 국가별 로더(요소 키 `iso3:elementId`, 팩 LRU 공용, `manifest.frameworkElements` 대조, 자산 URL 국가 루트 가드). `vietnamDataLoaderV124`는 기존 export를 유지하고 위임만 한다.
- `registryCountryDataProviderV158`: 이름·지도 시점을 레지스트리에서. 상태 `not-provided`.
- 레지스트리 로드 뒤 비기본 국가 provider 등록. `App`은 처음 연 `?country=`를 레지스트리 로드 뒤 다시 읽는다(뒤로 가기와 같은 경로).
- `useCountryDataProvidersV158`: 찾기·상세·다운로드의 국가 목록이 레지스트리 로드 뒤 갱신된다. 국가 구성이 같으면(지금 베트남만) 다시 그리지 않는다.
- `countryContext`: 번들 루트·live를 기본 국가 1개로(src의 비기본 국가 경로 0).

### 국가별 표시 계층
- `DataCountryContextV158`(페이지 국가·카탈로그 항목), `countrySpecV158`
  - 국가 고유 12요소(용역사 기준 11 + C-015)는 그 나라 `요소_KR`·`source_org`
  - 카드 출처는 모든 요소에서 그 나라 카탈로그 출처
  - 유형: #43 모델(`statusNotice`). 안내는 그 나라 카탈로그 상태로(미입고 → '데이터 준비 중'). 기본 국가의 제외·준비 중 안내는 넘어가지 않는다.
- 명세 문구: 타국 이름·지명(대상국 10개국, 레지스트리·사전에서 생성)이 든 문단·사례를 숨긴다. 원문은 고치지 않는다. 기본 국가 화면에는 적용하지 않는다.
- 공용 검수 문구(`countryCopyV158`): 분석 제목·차트 제목·지표 구분 문구가 타국 표현을 담으면 다른 나라 화면에서는 원자료 라벨·일반 제목으로.
- 작성 국가 문안 변형 22종은 다른 나라 화면에서 일반 템플릿으로(소스 검사 테스트가 누락을 막음).
- 지역명: 괄호 안은 로마자만(`presentation-v158.json` 지역 열). 개체명은 원문 그대로.
- 벵골 글꼴: Noto Sans Bengali 자체 호스팅(OFL 동봉, `unicode-range`) → 베트남 화면은 글꼴을 받지 않는다.
- 비교 블록: 공통 연도가 없으면 국가별 최신값·연도, 출처가 다르면 각주. 자기 나라 시계열이 없는 페이지에는 다른 나라끼리의 비교를 보이지 않는다.

### BGD 파생 자산·생성기
- 생성기 `--country`: semantic·카드 요약·dataset-directory·integrity. 비기본 국가일 때 src 파일은 쓰지 않는다.
- 베트남 재생성 결과는 PR 코드 = main 코드(바이트 동일). 아래 "기존 불일치" 참고.
- 카드 요약 생성기: C-007 국가 이름을 레지스트리에서, 등재 건수 행이 없으면 '0건' 대신 일반 항목 카드(결측 0 대체 금지). 베트남 출력 바이트 동일.
- 국가 비교 시계열 재생성(#43 비교 계약 반영, 58요소).
- integrity 생성기: `--data`가 다른 등록 국가의 공개 트리인데 `--country`가 다르면 중단(국가 인자 없이 BGD 트리를 지정하면 베트남 URL 접두사로 기록되던 문제). 출력은 BGD·VNM 모두 커밋본과 동일.

## 발견·결정 필요
1. **본부장 2026 제외 6건의 BGD 적용 여부**(PR-D 전 결정)
   - 결정 파일은 `config/data-publication/vietnam-exclusions-v156.json` 하나이고 문서는 "우리 플랫폼에서도 제외"라고 적는다.
   - BGD는 A-017(관측 72)·E-008(개체 544) 자료가 있고, C-020·C-021·E-016·E-017은 미입고다.
   - 지금 코드는 각 나라 카탈로그 상태를 따르므로, 결정 없이 BGD를 공개하면 A-017·E-008이 보인다. 적용하기로 하면 BGD ETL 공개 결정에 6건을 넣어 카탈로그부터 제외한다(PR-D).
2. **화면 서명 스크립트 주소 오류(V158-A 증거 범위)**: `?view=` 주소가 경로가 아니어서 찾기·지도·다운로드·이용안내 4화면이 모두 홈으로 찍혔다. V158-A의 "화면 변화 0"은 홈·상세 147개에 대해 유효하고, 4화면은 이번에 처음 실제로 비교했다.
3. **기존 불일치(main, fix-forward 대상)**: 베트남 semantic 계약 1파일·TS 모듈·dataset-directory 6요소(A-017·C-015·D-024·E-008·E-016·E-017)가 생성기 출력과 다르다. main 코드와 PR 코드의 출력이 바이트 동일하므로 이 PR과 무관하다. 재생성은 베트남 화면을 바꿀 수 있어 이 PR에서 하지 않았다.
4. 명세 문구 숨김 규모(BGD): 152요소 중 117요소에 영향, 사례 372건 중 179건 숨김, 검토 필요 약어 25개(`reports/v158/spec-text-hidden-bgd-v158.md`). 용역사에 국가 중립 문안을 요청할 근거로 쓴다.
5. 찾기 출처 필터에 BGD 출처 원문의 작업 메모('(용역사 취합)', '(자료별 상이 —참조)')가 보인다. 공개 출처 표기의 내부 메모 제거는 열린 PR #42 범위라서, BGD 공개(PR-D) 전에 #42 병합 뒤 다시 확인한다.
