# Public Naming Policy V131

## 목적

공개 카드, 표, 검색, 다운로드 미리보기, 지도 tooltip과 선택 패널에서 같은 원천 레코드를 일관되고 이해 가능한 이름으로 표시한다. 내부 식별자나 결측 placeholder는 공개 제목으로 사용하지 않는다.

## 제목 결정 순서

1. 원천이 제공한 공식 명칭: 사업명, 기관명, 회사명, 시설명, 문서명
2. 공식 공개 식별자와 자료 유형: 예) `Gold Standard 등록사업 · GS 1234`
3. 검증된 공개 사실의 조합: 국가, 기술, 용량, 연도 등
4. 해당 자료의 사용자용 유형: 탄소크레딧 사업, 적응기금 사업, 기업 진출 사례 등

원천에 없는 기업명·사업명·기관명은 생성하지 않는다. `명칭 미기재`, `unknown`, `N/A`, `null`, `undefined`, 내부 record 식별자는 primary title로 표시하지 않는다.

## 원문 명칭 부재

명칭 부재가 해석에 필요한 경우에만 `기업명 원문 미기재`, `사업명 원문 미기재`, `기관명 원문 미기재`와 같은 보조 설명을 제공한다. 이 설명은 제목보다 낮은 시각적 우선순위를 가진다.

같은 공식 명칭이 여러 공개 레코드에 반복되는 경우에는 검증된 연도·역할·거래규모·시설유형을 제목 뒤에 덧붙여 카드를 구분한다. record ID나 추정 정보는 사용하지 않는다.

## 적용 범위

- 데이터 상세의 카드와 원자료 표
- 검색·비교 화면의 entity 명칭
- 기본 CSV/JSON의 공개 `entity_name`
- 지도 point tooltip, 키보드 탐색, 선택 패널

공개 다운로드의 표시용 제목과 원천의 승인된 이름 필드는 별개로 유지하며, 내부 provenance 필드는 추가하지 않는다.

## 검증

`npm run audit:public-naming:v131`은 5,481개 공개 entity를 전수 검사한다. 빈 제목, placeholder 제목, technical primary label은 모두 0이어야 한다.
