# 공개 지표 해석 정책 V129

## 원칙

사용자가 값의 방향, 척도 또는 비교 단위를 직관적으로 알기 어려운 지표에는 검증된 해석을 제공한다. 설명이 필요 없는 인구, 시설 수, 면적, 일반 금액, 날짜 같은 값에는 빈 설명 영역이나 긴 일반 문구를 만들지 않는다.

해석은 runtime에서 원문 note를 임의 파싱해 생성하지 않는다. 공개 registry와 생성된 JSON을 같은 계약으로 유지하고 감사에서 양쪽의 일치를 확인한다.

## 설명 필요 판정

다음 성격을 가진 요소나 변수는 설명 대상이다.

- 지수, 점수, 등급, 순위
- 평가, 역량, 준비도, 거버넌스, 취약성, 위험, 신뢰도
- 복합지표와 방향이 직관적이지 않은 비율
- 분모가 화면에서 명확하지 않은 구성비
- 시나리오·전망값
- 상위 공간단위 값을 하위 공간단위 경계에 연결해 보여 주는 값

자동 탐지는 누락 후보를 찾는 장치다. 공개 여부와 실제 문구는 명시적 registry 항목으로 확정하며, 사용자에게 보이지 않는 분류·척도·임계값을 새로 만들지 않는다.

## 해석 계약

각 공개 해석은 다음 정보를 필요 범위에서 제공한다.

- 사용자용 지표·변수명
- 무엇을 측정하는지 설명하는 2~4개 짧은 문장
- 값이 높거나 낮을 때의 의미
- 공식 척도가 있을 때 최솟값·최댓값과 양 끝 의미
- 비교·집계 공간단위
- 분자·분모가 필요한 경우 그 정의
- 공식 근거가 있는 구간 또는 비교기준
- 출처기관과 공식 URL

방향은 `높을수록 긍정`, `높을수록 부정`, `순위가 낮을수록 긍정`, `중립`, `맥락에 따라 해석`으로 사용자 문구를 작성한다. 단순한 좋고 나쁨으로 해석할 수 없는 기대수명·소득 같은 구성변수는 사실적 방향과 한계를 함께 제시한다.

## 척도와 benchmark

- 공식 문서가 정의한 척도만 범위로 표시한다.
- 공식 구간이 없으면 임의 threshold를 `낮음·중간·높음`으로 만들지 않는다.
- percentile과 순위는 동일 정의·버전·연도·모집단을 검증한 경우에만 계산한다.
- 비교 자료를 확보하지 못하면 `세계적으로 높음/낮음` 같은 표현을 만들지 않는다.
- 계산된 중앙값·순위·percentile은 파생값임을 밝히고 비교 모집단을 표시한다.

## 공간 집계

상위 지역의 값을 여러 성·시 경계에 연결할 때는 값의 원래 집계단위를 tooltip, 범례와 분석 패널에 일관되게 표시한다. 반복된 성·시 feature 수로 순위를 계산하지 않고 고유 원천 지역 수로 계산한다.

### 지역 취약성 지표

- GVI 척도는 0~100이다.
- 0은 취약성이 매우 낮고 100은 매우 높으며, 높을수록 사회경제적 취약성이 크다.
- 성·시 경계에서 보여도 원래 값은 베트남 6개 권역 단위다.
- 순위는 63개 경계의 반복값이 아니라 6개 고유 원천 권역을 기준으로 한다.
- 선택한 구성변수의 사용자용 이름, 단위, 방향, 척도와 집계단위를 tooltip·범례·우측 패널에서 같은 계약으로 사용한다.
- 현재 source package와 동일 정의·버전·연도의 세계 분포를 검증하지 못했으므로 global percentile을 제공하지 않는다.

## 시각화 의미 적합성

해석 문구가 있어도 부적합한 시각화를 정당화할 수 없다. 서로 다른 분모, 방법론, 공간단위 또는 단위를 하나의 연속선·축에 연결하지 않는다. 결측은 0으로 대체하지 않으며, 실제 데이터가 없는 요소에는 상태 안내만 제공한다.

예산 배분처럼 분모와 보고서 판본이 다른 자료는 기준별로 분리한다. 대표 배분은 100% 구성으로 표시할 수 있지만 다른 기준을 연속 추세나 증감률로 연결하지 않는다.

## 현재 확인된 기준선

`reports/v129/interpretation-audit-v129.json`의 현재 기준선은 다음과 같다.

- 해석 필요 registry 항목: 53
- 자동 식별 비직관 요소: 43
- 해석 coverage: 100%
- 방향 누락: 0
- 필요한 척도 누락: 0
- 임의 공식 구간: 0
- 지역 취약성 변수: 12
- 지도 변수·단위 불일치: 0
- 세계 benchmark: 동일 버전 검증 불가로 미제공

이 수치는 기존 감사 보고서의 실제 결과를 기록한 기준선이며, 최종 공개 승인은 새 커밋에서 감사 명령을 다시 실행한 결과로 판정한다.
