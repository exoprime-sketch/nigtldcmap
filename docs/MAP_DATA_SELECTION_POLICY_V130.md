# Map Data Selection Policy V130

## 목적

V130 지도는 “좌표가 존재하는가”가 아니라 “그 좌표·경계가 사용자에게 어떤 공간 의미를 전달하는가”를 기준으로 데이터를 선택한다. 전체 152개 데이터는 데이터 찾기에서 제공하되, 지도에는 원천의 공간 해상도를 과장하지 않으면서 분석 이득을 주는 데이터만 포함한다.

## 필수 포함 기준

지도 데이터는 다음 조건을 모두 충족해야 한다.

1. 공개 가능한 geometry 또는 검증 위치가 있다.
2. 좌표·경계의 의미가 설명 가능하다.
3. 원천보다 세밀한 위치를 암시하지 않는다.
4. 결측을 0으로 대체하지 않는다.
5. centroid, 임의 연결선, 임의 위치 등 가짜 geometry를 만들지 않는다.
6. 공개·재배포 조건을 충족한다.
7. 지도 표현이 위치 분포, 네트워크, 지역 차이 또는 참여범위에 실질적 분석 이득을 준다.
8. 같은 의미의 사업을 한 프리셋에서 중복 표시하지 않는다.

## 금지되는 표현

- 다국가 사업의 첫 좌표를 전체 사업 위치로 표시
- 국가·권역 centroid를 물리적 시설로 표시
- 국가값을 성·시 값처럼 복제
- 지역 사업을 근거 없이 한 점으로 표시
- D-018과 D-023처럼 같은 사업을 중복 레이어에서 동시 표시
- 실제 표시 레코드보다 넓은 범위를 암시하는 레이어 제목

## V130 결정

- 지도 레이어: 12개
- 지도 피처·범위: 2,900개
- 전체 분류: 152/152
- D-023: 통합 포트폴리오로 데이터 찾기·상세 패널에 유지하되 지도에서는 제외
- D-018: Adaptation Fund 공간표현의 단일 책임 레이어
- C-025: 검증된 개별 사업지 18개만 표시. `gs_212`와 `gs_61`의 프로그램 대표좌표는 제외
- D-008: 실제 표시 내용에 맞게 공개 지도명을 “성·시 기후변화 지출”로 명확화

## 사용자 안내

공개 지도 패널의 “지도 데이터 안내”는 다음을 제공한다.

- 전체 데이터 152개와 지도 선택 데이터 12개의 구분
- 에너지·인프라, 산림·토지, 기후·위험, 물·자원, 국제사업·재원 그룹
- 각 레이어의 공간표현, 기준기간, 포함 이유, 공간 한계
- “전체 152개 데이터는 데이터 찾기에서 확인” 이동 링크

전체 결정 행은 `reports/v130/map-selection-152-v130.csv`와 `reports/v130/map-selection-152-v130.json`에 기록한다.
