# 공개 지도 상호작용 사양

## 목적과 적용 범위

이 문서는 베트남 공개 지도에 포함된 13개 데이터 레이어와 2,904개 지도 피처의 표시·탐색·선택 계약을 정의한다. 지도 피처는 `public/data/vietnam/v2/map-index.json`과 연결된 공개 데이터 팩, 공간 값 자산, 검증된 경계·송전망 자산을 기준으로 한다. 지도에 보이는 기호를 임의 레코드나 합성 값으로 보완하지 않는다.

## 레이어 역할

- 한 번에 주 분석 레이어는 최대 1개만 활성화한다.
- 보조 레이어는 최대 2개까지 활성화한다.
- 주 분석 레이어는 완전한 범례, selector, 전국 요약, 선택 상세를 제공한다.
- 보조 레이어는 낮은 시각적 우선순위로 표시하되 기호의 데이터명과 역할을 범례에 명시한다.
- 보조 피처를 선택해도 주 분석 레이어는 바뀌지 않는다. 우측 패널은 선택 대상을 `선택한 보조 데이터`로 식별한다.

## 공개 기호 계약

사용자 화면에는 구현 기술이나 원시 공간 형식 대신 다음 공간유형을 사용한다.

| 공개 공간유형 | 적용 대상 | 상호작용 |
| --- | --- | --- |
| 시설 위치 | 발전소, 주요 광산 | hover 요약, click 상세, 선택 halo |
| 사업 위치 | 탄소크레딧·적응기금·국제협력 사업 | hover 요약, click 상세, 선택 halo |
| 선형 인프라 | 송전망 | hover 전압·길이, click 구간 상세, 선택 강조 |
| 지역별 색상지도 | 취약성·산림·재생에너지·지역예산 | hover 값, click 지속 선택, 선택 윤곽선 |

범례는 활성 레이어마다 기호, 색상, 공개 데이터명, 주 분석/보조 역할, 선택 변수, 단위를 함께 표시한다. 색상만으로 레이어나 값을 구분하지 않는다.

## selector와 값의 일치

- selector의 변수 key, 사용자용 label, unit, 기간은 공간 값 자산의 `variable`, `variableLabel`, `unit`, `period`와 정확히 일치해야 한다.
- selector의 기본 변수와 기본 기간은 각각 제공 목록에 포함돼야 한다.
- 지역 값은 해당 공개 observation의 `sourceRecordId`와 canonical ADM1 code에 모두 연결돼야 한다.
- 결측값은 0으로 대체하지 않는다. 값이 없는 지역은 결측으로 표시한다.
- 지도 tooltip, 동적 범례, 우측 분석 패널은 동일한 selector 해석을 사용한다.

## 피처와 공개 상세 조인

### 위치 데이터

발전소(A-023), 주요 광산(B-048), 탄소크레딧 사업(C-025), 적응기금 사업(D-018), 국제협력·기후재원 사업(D-023)은 공개 entity의 `recordId`를 피처 선택 key로 사용한다. 지도에 투영되는 모든 entity는 다음 조건을 만족해야 한다.

- 공개 element와 피처 element가 일치한다.
- 중복되지 않은 record key가 있다.
- 원천이 제공한 유효 좌표가 있다.
- 공개 데이터명 또는 검증 가능한 공개 상세가 있다.
- 자료 제공기관과 기준기간이 있다.

레코드 lookup이 실패한 위치는 지도에 표시하지 않으며, 임의 레코드를 생성하지 않는다.

### 송전망

A-024는 검증된 송전망 606개 구간을 사용한다. 각 피처는 고유 feature key, 전압, 상태, 길이, 기준연도, 출처와 실제 선형 자산을 가져야 한다. 합성 선로나 임의로 연결한 좌표는 허용하지 않는다.

### 지역별 데이터

B-021, B-031, B-032, B-033, B-034, C-016, D-008은 개편 전 63개 성·시 경계를 공통 사용한다. 모든 공개 값은 존재하는 ADM1 code와 원 관측 record에 연결된다. selector 조합별 실제 coverage를 사용하며 국가값 복제나 결측 0 대체를 허용하지 않는다.

## B-021 권역 자료

- GVI와 구성지표는 GDL 6개 원천 권역 자료다.
- 권역 값을 명시적 membership으로 63개 성·시에 표시하되 성 단위 독립 추정값으로 설명하지 않는다.
- tooltip과 상세 패널은 원천 권역명을 표시한다.
- 순위는 반복된 63개 성 값이 아니라 6개 고유 `sourceRegion`과 6개 원 관측값으로 계산한다.
- GVI의 범위는 0–100이고 높을수록 사회경제적 취약성이 크다.
- 구성지표는 변수마다 label, unit, direction을 별도로 사용한다.
- 동일 정의·버전·연도의 공식 세계분포가 검증되지 않으면 세계 백분위나 세계적 높고 낮음을 표시하지 않는다.

## pointer, keyboard, touch

- point와 line은 충분한 투명 hit 영역을 둔다.
- polygon은 hover와 click 모두 지원하며 click 이후 선택을 유지한다.
- 선택 피처는 halo, 선 강조 또는 윤곽선으로 식별한다.
- 지도 키보드 탐색은 현재 활성 레이어의 피처를 순회하고 Enter 또는 Space로 선택한다.
- tooltip과 선택 상세는 키보드 탐색에서도 동일한 공개 내용을 제공한다.
- 새 주 분석 레이어를 선택하면 이전 피처 선택을 정리한다.

## 공개 상세 패널

선택 상세에는 공개 데이터명, 대상명, 현재 측정항목, 값, 단위, 기간, 자료 제공기관, 공개 유의사항, 공간 coverage, 상세 이동, 다운로드 상태를 제공한다. 내부 record key, 원본 행·시트, 구현 엔진, 원시 공간 형식은 DOM이나 tooltip에 노출하지 않는다.

## 최종 검증

`scripts/audit-vietnam-map-feature-join-v129.mjs`는 기존 V129 지도 상호작용 감사와 지표 해석 감사를 새로 실행한 뒤 다음을 추가로 전수 검사한다.

- 활성 레이어 13개, 지도 피처 2,904개, ADM1 63개
- 5개 위치 레이어의 모든 visible feature와 공개 entity 조인
- 송전망 606개 실제 피처의 필수 속성과 고유 key
- 7개 지역 레이어의 모든 공간 값과 observation·ADM1·selector 조인
- 13개 레이어의 hover tooltip과 click 상세
- 주 분석·보조 역할, 선택 상세, 기호 범례
- B-021 12개 변수의 label·unit·direction과 6개 권역 순위 계약
- orphan feature, unknown symbol, unclickable visible feature가 각각 0건

검사는 기존 브라우저 상호작용 게이트를 대체하거나 완화하지 않는다. 기존 게이트가 실패하면 피처 조인 감사도 실패한다.
