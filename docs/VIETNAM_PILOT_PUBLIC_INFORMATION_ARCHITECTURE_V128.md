# 베트남 파일럿 공개 정보구조 V128

## 목적과 범위

이 문서는 베트남 파일럿의 공개 화면과 이동 경로를 동결한다. 공개 화면은 정책연구자, 국제협력 기획자, 기업 및 연구기관이 데이터의 의미·범위·출처·이용조건을 일관되게 해석하도록 설계한다. 내부 ETL 상태, 원본 파일 위치, 레코드 식별자와 같은 기술 추적정보는 공개 화면에 전달하지 않는다.

공개 데이터의 단일 기준은 다음 자산이다.

- `public/data/vietnam/v2/manifest.json`: 릴리스 수치와 자산 위치
- `public/data/vietnam/v2/catalog.json`: 152개 요소의 계상·상태·출처·다운로드·지도 연결
- `public/data/vietnam/v2/framework-coverage.json`: 프레임워크 152개 요소의 포함 여부
- `public/data/vietnam/v2/quality-report.json`: 행 균형과 품질 경고
- `public/data/vietnam/v2/rights-matrix.json`: 원천 이용조건
- `public/data/vietnam/v2/asset-integrity.json`: 공개 자산 무결성
- `public/data/vietnam/v2/map-index.json`: 검증된 지도 13개 레이어
- `public/data/vietnam/v2/semantic/`: 측정항목·분류 차원·시각화 계약

화면 수치와 목록은 이 자산에서 파생하며 별도 상수로 복제하지 않는다.

## 공개 경로

| 경로 | 역할 | 핵심 내용 |
|---|---|---|
| `home` | 베트남 파일럿 진입 | 데이터 항목·제공·다운로드·지도 수치, 주요 데이터, 세 기능 진입점 |
| `explorer` | 데이터 찾기 | 152개 요소 검색, 필터, 정렬, 상태·출처·기간·다운로드·지도 표시 |
| `element-detail` | 단일 상세화면 | 이용 목적, 핵심현황, 분석, 유의사항, 출처, 접힌 원자료, 다운로드 |
| `map` | 공간 분석 | 검증된 13개 레이어, 주 분석 1개, 보조 2개, 5개 프리셋 |
| `download` | 공개 자료 내려받기 | 다중 선택, 예상 행 수, CSV/JSON, 출처·이용조건 |
| `guide` | 데이터 이용안내 | 상태·기간·결측·다운로드·지도 정확도·문의 원칙 |
| `not-found` | 오류 복구 | 404 설명, 홈과 데이터 찾기 복귀 |

브라우저 URL은 새로고침 후에도 국가, 요소, 측정항목, 기술, 연도·기간 선택을 복원한다. `#undefined`와 `#null`은 생성하지 않는다.

## 화면별 공개 계약

### 홈

- 제목은 “개도국 기후기술 협력 데이터 · 베트남 파일럿” 범위를 명확히 한다.
- 공개 현황은 manifest와 catalog에서 실시간 파생한다.
- 주요 데이터는 catalog에 존재하는 요소 4~8개만 사용한다.
- 주요 데이터는 `element-detail`로 이동하며 구형 dataset 상세로 이동하지 않는다.
- 실제 provider가 베트남 하나인 동안 다국가 제공을 주장하지 않는다.

### 데이터 찾기

- catalog 152개 요소가 모두 검색 가능하다.
- 검색 대상은 공개 데이터명, 측정항목, 분류, 기술, 기관, 정책, 사업, 지역, 출처기관이다.
- 정확한 데이터명, 부분 일치, 측정항목·기술, 기관·사업·지역 순으로 관련도를 계산한다.
- 카드에는 사용자용 상태와 별도의 다운로드 상태를 표시한다.
- 기본 이동은 `element-detail`이며 지도·다운로드는 보조 동작이다.

### 데이터 상세

표시 순서는 다음과 같다.

1. 이 데이터로 확인할 수 있는 내용
2. 핵심현황
3. 주 분석 시각화
4. 보조 분석 시각화
5. 실제 필요한 자료 이용 시 유의사항
6. 출처·기준연도
7. 원자료 보기(기본 접힘)
8. 다운로드 또는 화면 전용 사유

데이터가 없는 요소에는 가짜 KPI, 차트, 0값을 만들지 않는다. 상태와 향후 수집 방향만 제공한다.

### 데이터 지도

- 검증된 13개 레이어와 2,904개 feature, 베트남 63개 성·시 경계를 유지한다.
- 사용자는 주 분석 레이어 1개와 보조 레이어 최대 2개를 선택한다.
- 범례, 단위, 기준연도·기간, 전국 요약, feature 상세, 유의사항, 상세·다운로드 이동을 제공한다.
- 결측지역은 0으로 표시하지 않고 국가값을 지역값으로 복제하지 않는다.
- 지도 엔진, 원천 geometry 유형과 같은 구현 용어는 분석 본문에 표시하지 않는다.

### 다운로드

- 국가, 대분류, 그룹, 출처기관, 기술, 기간, 검색을 제공한다.
- 선택 데이터 수와 예상 공개 행 수를 다운로드 전에 표시한다.
- CSV는 UTF-8, JSON은 사용자용 공개 투영을 사용한다.
- 내부 ID, 원본 파일·시트·행, API 매개변수, 해시, 원시 속성을 포함하지 않는다.
- 내려받을 수 없는 데이터에는 “화면에서만 제공” 또는 “다운로드 자료 없음”과 사용자용 이유를 표시한다.

### 데이터 이용안내

공통 원칙은 개별 상세화면에 반복하지 않고 guide에서 설명한다. 데이터 제공 범위, 상태, 기준기간, 결측 처리, 다운로드, 출처·이용조건, 지도 정확도, 개편 전 베트남 63개 성·시 기준, 릴리스 일자와 문의 방법을 포함한다.

## 상태와 문구 일관성

내부 상태는 화면에 직접 표시하지 않는다. 모든 화면은 다음 사용자용 상태만 사용한다.

- 데이터 제공
- 일부 데이터 제공
- 입력 양식
- 입력 예정
- 원자료 미수집

다운로드 상태는 다음 중 하나다.

- 다운로드 가능
- 화면에서만 제공
- 다운로드 자료 없음

동일 요소의 제목과 상태는 홈, 검색, 카드, 상세, 지도, 다운로드에서 같아야 한다.

## 구형 경로 처리

| 구형 경로 | 공개 처리 |
|---|---|
| `dataset-detail` | 대응 요소가 있으면 `element-detail`, 없으면 `explorer` |
| `country` | `explorer?country=VNM` |
| `compare` | 다국가 비교가 가능해질 때까지 `download` 또는 `explorer` |
| `insights` | `explorer` |
| 과거 `guide` | 새 데이터 이용안내 |

구형 예시·mock 화면은 일반 이용자에게 렌더링하지 않는다. 동일 데이터에 서로 다른 공개 상세화면을 두지 않는다.

## 공개 필드 경계

공개 화면은 whitelist 투영만 받는다. 데이터명, 측정항목, 분류 차원, 값, 단위, 연도·기간, 지역·성별·기술·시나리오, 승인된 기관 속성, 사용자용 결측 사유, 출처기관·공식 URL·license·attribution을 허용한다.

원본 파일명, 시트명, 행 번호, 내부 indicator/record ID, API 매개변수, pack·shard, 해시, ETL 버전, 공개결정 ID는 공개 DOM·tooltip·aria-label·다운로드에 포함하지 않는다. CSS로 숨기지 않고 view model을 만들 때 제거한다.

## 접근성·반응형 기준

- 390px, 768px, 1024px, 1440px에서 가로 넘침이 없어야 한다.
- 키보드 포커스를 식별할 수 있고 모든 control에 접근 가능한 이름이 있어야 한다.
- 터치 control은 44px 이상을 목표로 한다.
- 차트 tooltip은 키보드로 접근 가능하고 색상 외 marker·pattern·텍스트를 병행한다.
- 지도 control은 키보드로 사용할 수 있다.
- loading, empty, error, 404 상태는 사용자가 다음 동작을 선택할 수 있는 문구를 제공한다.

## 동결 조건

V128 release audit가 다음을 모두 통과해야 공개 정보구조가 동결된다.

- 152개 데이터 요소와 상세 경로 계상
- 홈 수치와 manifest 일치
- 구형 화면 비노출 및 URL 복원
- 사용자용 상태·제목·출처·기간 일치
- 다운로드 행·권리·자산 reconciliation
- 공개 DOM 기술 토큰 0
- 브라우저 runtime error, JSON/GeoJSON 404·HTML 오응답, 깨진 내부 링크 0
- production build 성공
