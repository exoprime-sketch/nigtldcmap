## 구현

### B. 홈
- 상단: 국가 선택(현행) + **질문 6카드**(제목·한 줄 설명·대표 KPI 1개·"핵심 데이터 N개 보기"). 카드 클릭 → 데이터 찾기(해당 유형 + 핵심 필터).
- 기존 '주요 지역 데이터' 지도 미리보기는 유지하되 아래로, 카드 152 나열·카테고리 그리드는 제거(전체는 데이터 찾기에서).
- 첫 화면 텍스트 총량: 설명 문단 1개 이하, 본문 단어 수 현행 대비 −50% 이상(측정해서 보고).

### C. 데이터 찾기
- 기본 필터 `tier=core`(57), 상단 토글 **'전체 보기'**(보조·참고 포함 142). 유형(①~⑥)·주 사용자 필터 유지. URL에 `tier=` 보존.
- 카드: 출처 줄·원데이터명·간략 정의·KPI 1개(최신값·단위·연도)·유형 배지. 카드 안 차트 미리보기는 핵심 카드에서만 유지하고 보조·참고는 KPI만(성능·밀도).
- 검색은 전체 142 대상(참고 포함), 결과에 등급 배지.

### D. 상세 3층
- 1층(항상 펼침): 제목·출처 줄·간략 정의 → **판단 포인트** → 1순위 차트 | 지도 자리(2열) . 
- 2층(접힘, 제목만): '데이터 설명'(상세 설명·활용 방법·활용 사례), 2순위 차트, 연관 데이터 칩.
- 3층(접힘): 표·다운로드·출처(APA)·이용조건. 
- `<details>`/`aria-expanded`, 접힘 상태 localStorage 기억(요소별 아님, 전역), 인쇄 시 전부 펼침. 320px에서 1층만으로 첫 화면 완결.
- 문구 다이어트: 해석 안내·범례 설명·반복 제목 제거, 남는 설명 문단 화면당 1개. 용어 툴팁은 유지.
