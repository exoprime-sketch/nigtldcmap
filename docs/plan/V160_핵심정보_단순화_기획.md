## 1. 설계 원칙 5
1. **홈 = 질문 6개**: 카드 152개 나열 대신 "① 이 나라 수준은? ② 어디가 유리한가? ③ 어떤 기술이? ④ 무엇이 어디에·누구에게? ⑤ 누가 어디에 얼마나? ⑥ 규정·지원·리스크는?" 6개 진입점. 각 질문 아래 핵심 데이터 5~13개(§3)와 대표 KPI 1줄.
2. **데이터 찾기 기본 = 핵심 57개**: 목록·검색 기본 필터 '핵심'. '전체 보기' 토글로 보조·참고까지(142). 카드에는 출처 줄·원데이터명·간략 정의·KPI 1개만(차트 미리보기 제거 검토).
3. **상세 = 3층**: 1층(항상) 제목·간략 정의·**판단 포인트**·1순위 차트·지도 자리. 2층(접힘, 제목만 노출) 데이터 설명(상세 설명·활용 방법·활용 사례)·2순위 차트. 3층(접힘) 표·다운로드·출처·이용조건. 용어 툴팁 유지, 안내 문구 최소.
4. **지도 기본 레이어 = 핵심 ②④⑤ 중 지도 보유 요소만**(약 20개). 나머지 레이어는 '더 많은 레이어' 그룹 안. 연관 데이터 패널은 핵심 companions 1개만 기본, 나머지 접힘.
5. **문구 다이어트**: 화면당 설명 문단 1개 이하, 반복 안내·범례 설명·해석 안내 제거, 모든 숫자에 단위·연도.
