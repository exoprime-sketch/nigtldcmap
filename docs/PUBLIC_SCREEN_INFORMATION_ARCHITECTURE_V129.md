# 공개 화면 정보구조 V129

## 목적과 범위

이 문서는 베트남 공개 서비스에서 사용자가 접하는 화면, 화면 간 이동, 공통 문구와 공개 정보의 경계를 고정한다. 구현 세대명, 데이터 처리 내부 상태, 원본 파일 위치와 같은 운영 정보는 공개 화면 정보구조에 포함하지 않는다.

공개 서비스의 정식 명칭은 **개도국 기후기술 협력 플랫폼**이며, 현재 범위는 **현재 제공 국가 · 베트남**으로 표시한다. `베트남 파일럿`은 공개 화면의 H1이나 주요 내비게이션 명칭으로 사용하지 않는다.

## 공개 경로

| 화면 | 공개 목적 | 주 진입·이탈 경로 |
|---|---|---|
| 홈 | 서비스 범위, 핵심 기능, 데이터 현황과 대표 분석 데이터 안내 | 데이터 찾기, 지도, 다운로드, 이용안내 |
| 데이터 찾기 | 152개 요소 검색, 필터, 상태·기간·출처·지도·다운로드 가능 여부 확인 | 요소 상세, 지도, 다운로드 |
| 데이터 상세 | 데이터의 용도, 핵심현황, 적합한 분석, 해석, 출처, 제한, 원자료와 다운로드 제공 | 데이터 찾기, 지도, 다운로드 |
| 데이터 지도 | 검증된 13개 공간 데이터의 주 분석·보조 맥락 조합과 시설·선로·지역 탐색 | 요소 상세, 다운로드 |
| 데이터 다운로드 | 재배포 가능한 공개 요소 선택, 예상 행 수·형식·이용조건 확인 | 요소 상세, 이용안내 |
| 데이터 이용안내 | 상태, 기간, 결측, 다운로드, 출처·이용조건, 지도 정확도 안내 | 데이터 찾기, 지도, 다운로드 |
| 페이지 확인 불가 | 잘못된 주소에서 복구 경로 제공 | 홈, 데이터 찾기 |

구형 데이터 상세, 국가, 비교, 인사이트 경로가 공개 데이터와 다른 화면을 제공해서는 안 된다. 대응 가능한 요청은 현재 요소 상세 또는 데이터 찾기로 전환한다.

## 화면별 정보 순서

### 홈

1. 서비스명과 제공 국가
2. 데이터 검색
3. 데이터 찾기·지도·다운로드 진입
4. 실제 manifest와 catalog에서 계산한 데이터 현황
5. catalog에 존재하는 대표 분석 데이터

### 데이터 찾기

1. 검색·주제·상태·공간·기술 필터와 정렬
2. 결과 수
3. 데이터명과 사용자용 상태
4. 실제 공개 레코드, 기간, 측정항목, 분류, 출처기관
5. 지도·다운로드 상태와 이동 동작

동기화 대기 상태에서도 `semantic`, `renderer`, `의미 계약` 같은 내부 설계 용어를 사용하지 않는다. `측정항목 확인 중`, `분류 정보 확인 중`처럼 사용자가 기다리는 정보 자체를 설명한다.

### 데이터 상세

1. 이 데이터로 확인할 수 있는 내용
2. 핵심현황
3. 주 분석 시각화
4. 보조 분석 시각화
5. 필요한 경우에만 지표 읽는 법
6. 실제 항목이 있을 때만 자료 이용 시 유의사항
7. 출처·기준연도
8. 기본 접힘 상태의 원자료 보기
9. 다운로드 상태와 동작

실제 값이 없는 요소는 상태와 향후 수집 방향만 표시하며 차트나 0값을 만들지 않는다.

### 데이터 지도

1. 레이어 목록과 5개 분석 프리셋
2. 주 분석 레이어 1개와 보조 레이어 최대 2개
3. 선택 변수·기간·단위·공간 범위
4. 모든 활성 레이어의 기호와 역할을 식별하는 범례
5. 지도와 hover 안내
6. 전국 요약
7. 선택한 주 또는 보조 데이터의 공개 상세
8. 데이터 상세·다운로드 이동

지도에서 보이는 점·선·지역은 데이터명, 현재 변수와 단위를 확인할 수 있어야 한다. 지도 엔진, 원본 도형 형식과 내부 레이어 식별자는 분석 본문·tooltip·접근 가능한 이름에 표시하지 않는다.

## 사용자용 상태와 다운로드 문구

| 내부 판정 | 사용자용 상태 |
|---|---|
| 실제 데이터 또는 공개 결정에 따라 제공되는 데이터 | 데이터 제공 |
| 일부만 제공 | 일부 데이터 제공 |
| 입력 구조만 존재 | 입력 양식 |
| 향후 입력 대상 | 입력 예정 |
| 원자료 미확보 | 원자료 미수집 |

다운로드 상태는 `다운로드 가능`, `화면에서만 제공`, `다운로드 자료 없음` 중 하나만 사용한다. 화면에서만 제공하거나 자료가 없는 경우에는 사용자용 이유를 함께 제공한다.

## 공개 콘텐츠 경계

공개 화면에는 데이터명, 측정항목, 분류, 값, 단위, 기간, 지역·성별·기술·시나리오, 공개 승인된 기관 속성, 출처기관, 공식 URL, 라이선스, 사용자용 유의사항을 제공한다.

다음은 공개 문구, tooltip, 접근 가능한 이름과 표준 다운로드에 전달하지 않는다.

- 구현 세대명과 내부 설계 명칭
- 원본 파일·시트·행 위치
- 내부 레코드·지표 식별자
- API 매개변수, pack·shard·hash
- publication decision과 내부 download eligibility
- 지도 엔진 및 원본 도형 타입

CSS로 숨겨 공개 DOM에 남기는 방식이 아니라 공개 view model을 만들 때 제외한다.

## 수용 증거

공개 문구 수용검사는 production build를 정적 서버로 실행한 뒤 홈, 데이터 찾기, 152개 상세, 지도 초기 상태와 5개 프리셋, 다운로드, 이용안내, 404를 검사한다. 판정의 단일 증거는 `reports/v129/public-copy-audit-v129.json`이며, 빌드 이전의 소스 검색만으로 통과시키지 않는다.

최종 승인은 `npm run finalize:public-v129`의 모든 단계와 production browser QA가 통과한 커밋에 한정한다.
