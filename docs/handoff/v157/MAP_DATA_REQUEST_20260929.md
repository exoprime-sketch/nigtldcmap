## D. 재납품 요청 대상이 아닌 2건(참고)

- **A-013 NDC-SDG 지역조치**: 지역이 성·시 이름이 아니라 NDC 원문의 일반 지역어("coastal cities", "Mekong Delta")로만 등장한다. 원문을 바꿔 달라고 요청할 사안이 아니므로 **원문 인용 카드로만** 표시하고 경계는 만들지 않는다(연관 레이어 B-012·B-008).
- **A-022 전력공급 신뢰도**: EVN 그룹 전체 값만 존재하는 것은 원천(EVN 연차보고서)의 공개 수준 때문이다. 제공자 재납품 대신 **EVN 5개 총공사 관할표**(`tools/etl/countries/vnm/evn-jurisdiction.json`, 성별 출처 URL 필수)를 내부에서 작성해 관할 단위로 표시한다.
