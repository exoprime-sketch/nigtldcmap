## 1. A-023 발전소 — 레코드 급감 + 다른 요소의 템플릿 헤더

- **요소**: A-023(발전소[위치, 용량])
- **현상**
  - 개체 행 **1,963건 → 236건**. 236은 WRI Global Power Plant Database의 베트남 행 수와 일치
  - 개체 시트의 속성 열 머리글이 다른 요소 템플릿으로 채워져 있음: `속성1(A-013:SDG세부목표코…)`, `속성2(A-013:정보유형…)`, `속성3(A-024:선로상태(기존/…)`
  - 그 결과 현재 공개 화면이 쓰는 발전원·설비용량·소유·운영·가동 연도·소재지 열이 없음
- **요청 사항**
  - A-023 전용 속성 열로 다시 생성(발전원, 설비용량(MW), 소유·운영 주체, 가동 연도, 소재지(성·시), 좌표, 출처 URL)

- **재납품 기준**: 개체 시트에 위 7개 속성 열이 존재하고, 각 행의 발전원·설비용량이 채워져 있거나 결측사유코드가 기재된 상태

## 4. E-008 논문·특허 — 메타정보 시트에 API 인증키 포함

- **요소**: E-008(논문, 특허)
- **현상**
  - `2_meta_info` 시트 **6행·8행**의 `api_params` 열(14열)에 OpenAlex API 질의 문자열이 들어 있고, 그 안에 인증키 파라미터가 포함되어 있음
  - 키 값 자체는 이 문서·저장소·보고서·로그 어디에도 기록하지 않았습니다(해시·길이만 내부 기록)
  - ETL은 해당 값을 공개 산출물에서 제외하고 빌드를 중단시켜 사람의 확인을 요구합니다. 현재 공개 트리에는 인증키가 포함된 이력이 없습니다
- **요청 사항**
  - 해당 키를 **폐기·재발급**(rotate). 워크북 파일 형태로 배포된 이력이 있으므로 노출된 것으로 간주해 주시기 바랍니다
  - 차기 입고분부터 메타정보 시트에는 엔드포인트·파라미터 이름만 적고 인증키·토큰·비밀번호 값은 넣지 않기
  - 이미 배포된 2026-09-22 입고분 폴더는 공유·업로드를 중단해 주시기 바랍니다(값이 남아 있음)
- **재납품 기준**: `api_params` 등 메타정보 열에 인증키·토큰 값이 없는 상태. 플랫폼 측 탐지 규칙은 `tools/vietnam_etl/normalization.py`의 자격증명 패턴을 사용합니다
