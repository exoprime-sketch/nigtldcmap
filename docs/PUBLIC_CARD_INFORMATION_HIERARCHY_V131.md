# Public Card Information Hierarchy V131

## 공통 구조

공개 entity 카드는 다음 순서를 사용한다.

1. 분류 badge 2~4개 이내
2. 의미 있는 primary title, 최대 2줄
3. 핵심 사실 최대 6개
4. 필요한 경우에만 공식 원문 링크

긴 원문 note, 출처 인용문 전체, pipe로 연결된 원자료 문장, 중요하지 않은 결측 필드는 기본 카드에서 제외한다. 전체 정보는 접힌 `원자료 보기`와 상세 화면에서 확인한다.

## 유형별 우선순위

| 템플릿 | 우선 표시 정보 |
|---|---|
| 사업·포트폴리오 | 상태, 기관·재원, 분야·유형, 규모, 지원대상, 기간 |
| 기관 디렉터리 | 기관명, 기관유형, 주요 업무, 위치, 담당자, 연락처 |
| 투자·기업 | 회사·사업명, 국가, 기술, 진출형태, 규모, 확인연도 |
| 문헌·연구 | 문서명, 유형, 기술분야, 공개연도, 발행처, DOI |
| 지원 프로그램 | 프로그램명, 지원유형, 대상, 한도, 신청기간 |
| 일반 entity | 자료 유형, 상태, 지역, 기준연도 |

## 밀도와 반응형

- 1,240px 이상: 최대 4열
- 960~1,239px: 최대 3열
- 620~959px: 최대 2열
- 619px 이하: 1열

5열 강제 배치는 사용하지 않는다. 제목은 2줄로 제한하되 전체 의미를 aria-label로 제공한다. 키보드 focus는 공식 원문 링크에서 명확히 표시한다.

## 금지 사항

- `명칭 미기재` 또는 `자료 없음`을 카드 heading으로 사용
- source row/sheet, record ID, 파일명, 내부 버전을 DOM 속성에 포함
- 같은 제목의 카드가 공개 사실로도 구분되지 않는 상태
- 한 카드에 6개보다 많은 facts 또는 긴 비구조 문장 표시

`npm run audit:entity-cards:v131`은 30개 entity route, 309개 대표 카드와 6개 viewport를 production build에서 검사한다.
