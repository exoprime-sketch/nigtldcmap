# 지도 분석 벤치마크 계약 V133

## 목적

V133 지도는 외부 플랫폼의 외형을 복제하지 않는다. 공간자료를 고르는 방식, 범례를 유지하는 방식, hover와 click을 나누는 방식처럼 사용자가 해석에 필요한 기능 원칙만 적용한다.

## 적용 원칙

| 참고 플랫폼 | 확인한 기능 원칙 | V133 적용 |
| --- | --- | --- |
| Global Forest Watch | 활성 레이어 범례, 선택 지역 분석, 지도와 추이 연결 | 표시 중인 모든 데이터의 기호·단위를 범례에 유지하고, 선택 지역의 상세·추이가 있으면 우측 분석에 연결 |
| Resource Watch | 다차원 자료의 핵심 공간 subset과 전체 자료 접근 분리 | 지도에는 공간 의미가 검증된 12개 자료만 표시하고 152개 전체 자료는 상세·다운로드로 제공 |
| World Bank Maps | 사업 필터와 사업 수·금액·위치 요약 후 탐색 | 기후재원 프리셋에서 적응기금·탄소크레딧 유형을 먼저 고르고 요약 뒤 개별 사업 확인 |
| World Bank CCKP | 변수·기간·공간수준 선택과 의미 설명 | 변수·자료연도·공간단위를 함께 표시하고 B-021의 권역값을 성·시 개별값으로 오해하지 않도록 설명 |
| Esri Living Atlas / ArcGIS Online | 목적에 맞게 구성한 popup, 관련 없는 원시 필드 비노출 | hover는 빠른 판단용 5개 이하 정보 블록, click은 승인된 공개 필드로 구성한 분석 패널 |
| 산림공간정보서비스 | 범례조회·표시 설정·상세 속성정보 등 직관적 한국어 | `주 분석 데이터`, `함께 보기`, `표시 설정`, `범례`, `상세 정보` 용어로 통일 |

## 지도 상호작용 계약

1. 프리셋 선택 직후에는 주 분석 데이터만 표시한다.
2. 함께 볼 자료는 사용자가 직접 켠 경우에만 표시하며 최대 두 개다.
3. 동일 화면의 지역 통계 두 개를 중첩 색상면으로 표현하지 않는다. B-021은 지역 색상, D-008은 성·시 통계 비례 원, D-018은 검증된 활동지 또는 지역 협력범위로 구분한다.
4. hover는 지명·측정항목·값·단위·방향 또는 상태·한 줄 맥락까지만 제공한다.
5. click은 선택 지역 또는 선택 사업의 비교, 공간단위, 출처, 상세 이동을 제공한다.
6. 중첩 대상은 선택 항목, 주 분석 데이터, 마지막으로 켠 함께 보기, 나머지 함께 보기 순으로 결정한다. 동순위 대상은 선택목록으로 제시한다.
7. 원시 속성 덤프와 내부 코드·개발자 용어는 공개 DOM에 전달하지 않는다.
