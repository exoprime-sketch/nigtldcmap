# V160 핵심 정보 우선

기획: `docs/plan/V160_핵심정보_단순화_기획.md`, 실행 지시: `docs/plan/P11_V160_핵심정보_단순화.md`.

## 원칙

- 데이터·요소는 지우지 않는다. 기본 화면에서 **순서와 접힘**만 바꾼다(전체 보기·더 많은 레이어·2/3층에서 모두 열람 가능).
- 등급은 코드에 쓰지 않는다. 기획서 §3 표 → `scripts/v160/build-core-first-v160.mjs` → `src/data/spec/informationTiersV160.json`이 정본(`check:core-first:v160`로 동기 확인).
- 대표 KPI는 카드 요약(`card-summaries-v140.json`) 헤드라인이 요청한 수치일 때만 표시한다. 없으면 자리를 숨긴다(추정 금지).
- 지도 데이터·map-index·빌더·렌더러는 불변. 기본 레이어 목록 파일(`src/data/map/mapDefaultLayersV160.json`)과 목록 UI만 바꾼다.

- 히어로(제목·설명 1문단·검색) → **질문 6카드**(유형 ①~⑥) → 지도 미리보기 → 통계.

## 데이터 찾기

- 기본 '핵심' 57, '전체 보기' 141(`tier=all`). 검색하면 전체로 전환.
- 카드에 등급·유형 표시, 보조·참고 카드는 KPI 한 줄만.

## 상세 3층

- 1층(상시): 제목·출처 줄·간략 정의 → 판단 포인트(넓은 화면 2열) → 1순위 차트 | 지도 자리.
- 2층(접힘) '데이터 설명': 핵심 수치 띠, 상세 설명·활용 방법·활용 사례.
- 3층(접힘) '다운로드·참고문헌': 출처(APA)·상세 표·다운로드.
- `<details>` + summary `aria-expanded`, 열림 상태는 전역 localStorage(`detail-layers-v160`), 인쇄 시 전부 펼침.

## 지도

- '핵심 레이어' 20개(핵심 등급 · 유형 ②④⑤ · map-index 활성) 기본 펼침, 나머지 6분류는 '더 많은 레이어' 아래 접힘. `layers=all`이면 모두 펼침.
