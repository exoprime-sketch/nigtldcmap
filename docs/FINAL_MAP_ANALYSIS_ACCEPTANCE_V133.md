# 최종 지도 분석 수용 기준 V133

## 데이터 계약

- framework element 152개와 accounted element 152개를 유지한다.
- 최종 지도 레이어는 12개이며 D-023 중복 표현을 복원하지 않는다.
- V130의 지역 협력사업 공간 의미, V131의 공개 이름, V132의 분석 우선 시각화를 회귀시키지 않는다.

## 사용자 상태 계약

- 프리셋 직후 기본 함께 보기 수는 0이다.
- 주 분석 데이터는 최대 1개, 함께 보기는 최대 2개다.
- 기후 취약성은 지역 색상, 지역 기후예산은 성·시 단위 비례 원, 적응기금은 마름모 또는 지역 협력범위로 식별한다.
- B-021 GVI 순위는 성·시 63개 반복값이 아니라 같은 연도의 6개 고유 `sourceRegion` 값으로 계산한다.
- hover에는 긴 방법론을 넣지 않고 click 상세에 공간단위·비교·자료 설명을 제공한다.
- 중첩 대상의 선택 우선순위는 결정적이며 필요한 경우 선택목록을 제공한다.

## 자동 수용검사

`npm run finalize:v133`은 Git에 포함된 생성 산출물 검사, CI 계약, V133 지도 production runtime 검사와 이전 버전 회귀 검사를 실행한다. 로컬 원자료 ZIP 검사는 `audit:source-local:v133`으로 분리하며 CI 배포 조건에 포함하지 않는다.

성공 조건은 다음과 같다.

- 원자료 ZIP을 요구하지 않는 CI release gate
- 생성 자산 hash 실패 0건
- 기본 함께 보기 0개
- 보이지 않는 기호 또는 범례 누락 0건
- hover 핵심값 누락 0건
- click 상세 누락 0건
- 공개 지도 내부 토큰 0건
- console 오류 0건, 깨진 asset 0건
- 필수 screenshot 9개 및 viewport 390/768/1024/1440/1920 검증
